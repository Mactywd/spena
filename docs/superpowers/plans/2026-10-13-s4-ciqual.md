# S4, fetta 1 — I nutrienti dell'ingrediente da CIQUAL: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ogni ingrediente alimentare può avere un alimento della tabella CIQUAL 2025 che gli dà i nutrienti medi per 100 g, con la provenienza e il riferimento; l'AI lo sceglie fra candidati veri, Mattia lo corregge in Anagrafica, e un pilota misura se Gemma basta prima del lancio su tutto il catalogo.

**Architecture:** un modulo puro (`backend/app/domain/ciqual.py`) sa leggere le colonne e i valori di CIQUAL; un lettore XLSX con la sola libreria standard (`services/ciqual_file.py`) li carica in `ciqual_foods` col comando `load_ciqual`; `ingredient_nutrition` (migrazione `0016`) lega un ingrediente a un codice CIQUAL, con tre stati (nessuna riga, codice NULL, un codice) e `decided_by`. L'AI decide in due passi (`services/ciqual_match.py`: parole di ricerca in francese, poi la scelta fra i candidati che `pg_trgm` trova), sotto il comando `decide_ciqual`; il pilota (`s4_pilot`) usa gli stessi servizi su 30 casi con la risposta nota. Le scelte passano da un servizio solo (`services/ingredient_nutrition.py`), le rotte stanno in `api/nutrition.py`, e la scheda dell'ingrediente in Anagrafica ha una sezione nuova, «Valori nutrizionali», con la ricerca per la correzione.

**Tech Stack:** FastAPI, SQLAlchemy async, Alembic, pytest su Postgres vero (`pg_trgm`); `zipfile` e `xml.etree` della libreria standard; OpenRouter tramite `services/llm.py` (`complete_json`), provato con i finti di `backend/tests/llm_fakes.py`; React 19, TypeScript, Tailwind 4 (token in `@theme`), TanStack Query 5, Vitest + Testing Library (jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-s4-nutrienti-ingrediente-design.md` — §2 (le decisioni di Mattia del 2026-10-13), §3 (la ricerca), §4 (le decisioni di Claude su delega, 1–19 per questa fetta), §5 (comportamento e parole a video), §10–§12. In `docs/prossimi-passi.md` la voce **[S4]**. Le decisioni sono riportate sotto, in «Decisioni prese».

La seconda (`docs/superpowers/plans/2026-10-13-s4-grammi.md`, ramo `night/s4-grammi` che parte da questo) aggiunge i grammi delle dosi e i nutrienti di una ricetta.

```python
dalla posizione, e l'unità scritta nell'intestazione si confronta con quella del

# «Fer (mg/100 g)»: il nome, poi fra parentesi l'unità per 100 g. Il nome può avere una
# barra sua («1169/2011»), l'unità no.
_HEADER = re.compile(r"^(?P<name>.+?)\s*\((?P<unit>[^()/]+)/\s*100\s*g\)\s*$")
_FLOAT_CODE = re.compile(r"^\d+\.0+$")


class CiqualFormatError(Exception):
    """Il file non è quello atteso: niente si scrive, e il messaggio dice perché."""


def normalize_name(text: str) -> str:
    """Minuscolo, senza accenti, spazi semplici, «N°» attaccato al numero."""
    text = text.replace("œ", "oe").replace("Œ", "Oe").replace("º", "°")
    plain = "".join(
        char for char in unicodedata.normalize("NFKD", text) if not unicodedata.combining(char)
    ).lower()
    plain = re.sub(r"n\s*°\s*", "n°", plain)
    return " ".join(plain.split())


def normalize_unit(unit: str) -> str:
    """«µg», «μg» (la lettera greca) e «mcg» sono la stessa unità: «ug»."""
    plain = unicodedata.normalize("NFKC", unit).strip().lower()
    return plain.replace("μ", "u").replace("mcg", "ug")


def split_header(header: str) -> tuple[str, str] | None:
    """Il nome normalizzato e l'unità di una colonna di costituente, o `None` per le
    altre (`alim_code`, `alim_nom_fr`, …)."""
    found = _HEADER.match(header.strip())
    if found is None:
        return None
    return normalize_name(found["name"]), normalize_unit(found["unit"])


def parse_teneur(raw: str | None) -> float | None:
    """Il valore di una cella. `None` vuol dire assente — mai zero (CLAUDE.md).

    «traces» è 0, perché la tabella dice che c'è, in quantità trascurabile; «< x» è x/2,
    la convenzione «middle bound» dell'EFSA: il valore vero sta fra 0 e il limite (spec
    §4.4). Qualunque altra cosa che non sia un numero solleva `ValueError`: chi legge il
    file la conta come illeggibile e la lascia assente.
    """
    if raw is None:
        return None
    text = raw.replace(" ", " ").strip()
    if text in _EMPTY:
        return None
    if text.lower() == "traces":
        return 0.0
    below = text.startswith("<")
    value = float(text.lstrip("<").strip().replace(",", "."))
    if not math.isfinite(value) or value < 0:
        raise ValueError(text)
    return value / 2 if below else value


def normalize_code(raw: str | None) -> str | None:
    """Il codice come testo. Un foglio che l'ha salvato come numero lo scrive «20047.0»."""
    if raw is None:
        return None
    text = raw.strip()
    if _FLOAT_CODE.match(text):
        text = text.split(".")[0]
    if not text or len(text) > CODE_MAX_LENGTH:
        return None
    return text


@dataclass(frozen=True)
class ColumnMap:
    code: int
    name: int
    group: int | None
    subgroup: int | None
    # chiave del vocabolario → indice della colonna
    nutrients: dict[str, int]
    # le chiavi di `CIQUAL_NAMES` che il file non ha
    absent: tuple[str, ...]
    # le colonne di costituente che nessuna chiave usa («Eau (g/100 g)»): si dicono
    unused: tuple[str, ...]


def map_columns(headers: list[str | None]) -> ColumnMap:
    """Quale colonna è quale. Solleva `CiqualFormatError` se il file non va."""
    wanted = {name: key for key, names in CIQUAL_NAMES.items() for name in names}
    identity: dict[str, int] = {}
    nutrients: dict[str, int] = {}
    unused: list[str] = []
    for index, header in enumerate(headers):
        if header is None:
            continue
        plain = header.strip()
        if plain in (CODE_COLUMN, NAME_COLUMN, GROUP_COLUMN, SUBGROUP_COLUMN):
            identity.setdefault(plain, index)
            continue
        split = split_header(plain)
        if split is None:
            continue
        name, unit = split
        key = wanted.get(name)
        if key is None:
            unused.append(plain)
            continue
        field = NUTRIENT_FIELDS[key]
        if unit != normalize_unit(field.unit):
            raise CiqualFormatError(
                f"la colonna «{plain}» è in {unit}, ma «{field.label}» si conta in "
                f"{field.unit}: il file non è quello atteso"
            )
        nutrients.setdefault(key, index)
    missing = [column for column in (CODE_COLUMN, NAME_COLUMN) if column not in identity]
    if missing:
        raise CiqualFormatError(
            f"mancano le colonne {', '.join(missing)}: il file non è la tabella CIQUAL"
        )
    required = [NUTRIENT_FIELDS[key].label for key in REQUIRED_KEYS if key not in nutrients]
    if required:
        raise CiqualFormatError(
            f"non trovo le colonne di {', '.join(required)}: il file non è quello atteso"
        )
    return ColumnMap(
        code=identity[CODE_COLUMN],
        name=identity[NAME_COLUMN],
        group=identity.get(GROUP_COLUMN),
        subgroup=identity.get(SUBGROUP_COLUMN),
        nutrients=nutrients,
        absent=tuple(key for key in CIQUAL_NAMES if key not in nutrients),
        unused=tuple(unused),
    )


@dataclass(frozen=True)
class CiqualRow:
    code: str
    name_fr: str
    group_fr: str | None
    # chiave del vocabolario → valore per 100 g; un nutriente assente non c'è
    nutrients: dict[str, float]


def _text(cells: list[str | None], index: int | None) -> str:
    if index is None or index >= len(cells):
        return ""
    value = (cells[index] or "").strip()
    return "" if value in _EMPTY else value


def food_from_row(
    cells: list[str | None], columns: ColumnMap
) -> tuple[CiqualRow | None, list[str]]:
    """L'alimento di una riga, e le chiavi con un valore illeggibile.

    `None` per una riga senza codice o senza nome: le righe vuote in fondo a un foglio,
    o una riga di titolo.
    """
    code = normalize_code(cells[columns.code] if columns.code < len(cells) else None)
    name = _text(cells, columns.name)
    if not code or not name:
        return None, []
    group = _text(cells, columns.subgroup) or _text(cells, columns.group) or None
    values: dict[str, float] = {}
    unreadable: list[str] = []
    for key, index in columns.nutrients.items():
        try:
            value = parse_teneur(cells[index] if index < len(cells) else None)
        except ValueError:
            unreadable.append(key)
            continue
        if value is not None:
            values[key] = value
    return (
        CiqualRow(
            code=code,
            name_fr=name[:NAME_MAX_LENGTH],
            group_fr=group[:GROUP_MAX_LENGTH] if group else None,
            nutrients=values,
        ),
        unreadable,
    )
```

```python
def _letters(index: int) -> str:
    """0 → A, 25 → Z, 26 → AA: il riferimento di colonna di un foglio."""
    letters = ""
    index += 1
    while index:
        index, rest = divmod(index - 1, 26)
        letters = chr(ord("A") + rest) + letters
    return letters


def write_xlsx(path: Path | str, rows: list[list[object]]) -> None:
    strings: list[str] = []
    positions: dict[str, int] = {}

    def shared(text: str) -> int:
        if text not in positions:
            positions[text] = len(strings)
            strings.append(text)
        return positions[text]

    sheet_rows = []
    for number, row in enumerate(rows, start=1):
        cells = []
        for column, value in enumerate(row):
            if value is None:
                continue  # una cella vuota non si scrive, come fa Excel
            reference = f"{_letters(column)}{number}"
            if isinstance(value, (int, float)):
                cells.append(f'<c r="{reference}"><v>{value}</v></c>')
            else:
                cells.append(f'<c r="{reference}" t="s"><v>{shared(str(value))}</v></c>')
        sheet_rows.append(f'<row r="{number}">{"".join(cells)}</row>')

    head = '<?xml version="1.0" encoding="UTF-8" standalone="yes"?>'
    with zipfile.ZipFile(path, "w", zipfile.ZIP_DEFLATED) as archive:
        archive.writestr(
            "[Content_Types].xml",
            f'{head}<Types xmlns="http://schemas.openxmlformats.org/package/2006/content-types">'
            '<Default Extension="xml" ContentType="application/xml"/></Types>',
        )
        archive.writestr(
            "xl/workbook.xml",
            f'{head}<workbook xmlns="{MAIN}" xmlns:r="{DOC_REL}"><sheets>'
            '<sheet name="Ciqual" sheetId="1" r:id="rId1"/></sheets></workbook>',
        )
        archive.writestr(
            "xl/_rels/workbook.xml.rels",
            f'{head}<Relationships xmlns="{PKG_REL}"><Relationship Id="rId1" '
            f'Type="{DOC_REL}/worksheet" Target="worksheets/sheet1.xml"/></Relationships>',
        )
        archive.writestr(
            "xl/worksheets/sheet1.xml",
            f'{head}<worksheet xmlns="{MAIN}"><sheetData>{"".join(sheet_rows)}</sheetData></worksheet>',
        )
        archive.writestr(
            "xl/sharedStrings.xml",
            f'{head}<sst xmlns="{MAIN}" count="{len(strings)}" uniqueCount="{len(strings)}">'
            + "".join(f"<si><t>{escape(text)}</t></si>" for text in strings)
            + "</sst>",
        )
```

```python
"""Il file della tabella CIQUAL, letto da un XLSX con la sola libreria standard (S4, fetta 1).

Un XLSX è un archivio zip di XML: il foglio, e a parte le stringhe che il foglio cita per
numero (`sharedStrings.xml`). Leggerlo con `zipfile` e `xml.etree` evita una dipendenza
(`openpyxl`) per un file che si carica una volta all'anno (spec §4.2). Il foglio si legge
a righe, in streaming (`iterparse`).

Le celle vuote un XLSX non le scrive: la posizione di una cella sta nel suo riferimento
(`r="AB12"`), e una riga si ricostruisce da lì, non dall'ordine in cui arrivano. Senza,
una vitamina mancante sposterebbe di una colonna tutti i valori dopo di lei.

Il file viene da Mattia, scaricato dalla scheda ufficiale (spec §3): non è un file che
arriva da uno sconosciuto. Il parser di `xml.etree` (expat) rifiuta comunque l'espansione
ricorsiva delle entità.
"""

import re
import zipfile
from collections import Counter
from collections.abc import Iterator
from dataclasses import dataclass
from pathlib import Path
from xml.etree.ElementTree import Element, ParseError, iterparse, parse

from app.domain.ciqual import (
    CODE_COLUMN,
    CiqualFormatError,
    CiqualRow,
    food_from_row,
    map_columns,
)

_MAIN = "{http://schemas.openxmlformats.org/spreadsheetml/2006/main}"
_DOC_REL = "{http://schemas.openxmlformats.org/officeDocument/2006/relationships}"
_PKG_REL = "{http://schemas.openxmlformats.org/package/2006/relationships}"
_COLUMN = re.compile(r"^([A-Z]+)")

# Dove si cerca la riga con `alim_code`: un foglio può avere un titolo sopra.
HEADER_SEARCH_ROWS = 10


def _column_index(reference: str) -> int | None:
    found = _COLUMN.match(reference)
    if found is None:
        return None
    index = 0
    for letter in found.group(1):
        index = index * 26 + (ord(letter) - ord("A") + 1)
    return index - 1


def _shared_strings(archive: zipfile.ZipFile) -> list[str]:
    if "xl/sharedStrings.xml" not in archive.namelist():
        return []
    strings: list[str] = []
    with archive.open("xl/sharedStrings.xml") as stream:
        for _, element in iterparse(stream):
            if element.tag == f"{_MAIN}si":
                strings.append("".join(text.text or "" for text in element.iter(f"{_MAIN}t")))
                element.clear()
    return strings


def _first_sheet(archive: zipfile.ZipFile) -> str:
    workbook = parse(archive.open("xl/workbook.xml")).getroot()
    sheet = workbook.find(f"{_MAIN}sheets/{_MAIN}sheet")
    if sheet is None:
        raise CiqualFormatError("il file XLSX non ha fogli")
    rel_id = sheet.get(f"{_DOC_REL}id")
    relations = parse(archive.open("xl/_rels/workbook.xml.rels")).getroot()
    for relation in relations.iter(f"{_PKG_REL}Relationship"):
        if relation.get("Id") == rel_id:
            target = relation.get("Target") or ""
            return target.lstrip("/") if target.startswith("/") else f"xl/{target}"
    raise CiqualFormatError("il file XLSX non dice dove sta il suo primo foglio")


def _cell_value(cell: Element, strings: list[str]) -> str | None:
    kind = cell.get("t")
    if kind == "inlineStr":
        return "".join(text.text or "" for text in cell.iter(f"{_MAIN}t"))
    raw = cell.findtext(f"{_MAIN}v")
    if raw is None:
        return None
    if kind == "s":
        return strings[int(raw)]
    return raw


def read_xlsx_rows(path: Path) -> Iterator[list[str | None]]:
    """Le righe del primo foglio, ogni cella al suo posto (`None` dove non è scritta)."""
    with zipfile.ZipFile(path) as archive:
        strings = _shared_strings(archive)
        with archive.open(_first_sheet(archive)) as stream:
            for _, element in iterparse(stream):
                if element.tag != f"{_MAIN}row":
                    continue
                cells: dict[int, str | None] = {}
                position = 0
                for cell in element.iter(f"{_MAIN}c"):
                    index = _column_index(cell.get("r", ""))
                    if index is None:
                        index = position
                    position = index + 1
                    cells[index] = _cell_value(cell, strings)
                element.clear()
                width = max(cells) + 1 if cells else 0
                yield [cells.get(index) for index in range(width)]


@dataclass(frozen=True)
class CiqualFile:
    foods: list[CiqualRow]
    # chiave → quanti alimenti hanno un valore
    with_value: dict[str, int]
    # chiave → quante celle non si sono lette
    unreadable: dict[str, int]
    # le chiavi del vocabolario che il file non ha
    absent: tuple[str, ...]
    # le colonne di costituente che nessuna chiave usa
    unused: tuple[str, ...]
    # righe con qualcosa scritto ma senza codice o senza nome
    skipped_rows: int
    # righe con un codice già letto: vale la prima
    duplicate_codes: int


def read_ciqual(path: Path) -> CiqualFile:
    """Tutto il file, o `CiqualFormatError` col perché. Non tocca il database."""
    try:
        return _read(path)
    except CiqualFormatError:
        raise
    except (OSError, zipfile.BadZipFile, KeyError, IndexError, ValueError, ParseError) as exc:
        raise CiqualFormatError(
            f"«{path.name}» non si legge come il file XLSX di CIQUAL ({exc})"
        ) from exc


def _read(path: Path) -> CiqualFile:
    rows = read_xlsx_rows(path)
    try:
        headers = None
        for _ in range(HEADER_SEARCH_ROWS):
            candidate = next(rows, None)
            if candidate is None:
                break
            if any((cell or "").strip() == CODE_COLUMN for cell in candidate):
                headers = candidate
                break
        if headers is None:
            raise CiqualFormatError(
                f"nelle prime {HEADER_SEARCH_ROWS} righe non c'è l'intestazione con "
                f"«{CODE_COLUMN}»: il file non è la tabella CIQUAL"
            )
        columns = map_columns(headers)
        foods: dict[str, CiqualRow] = {}
        with_value: Counter[str] = Counter()
        unreadable: Counter[str] = Counter()
        skipped = duplicates = 0
        for cells in rows:
            food, bad = food_from_row(cells, columns)
            if food is None:
                if any((cell or "").strip() for cell in cells):
                    skipped += 1
                continue
            if food.code in foods:
                duplicates += 1
                continue
            foods[food.code] = food
            unreadable.update(bad)
            with_value.update(food.nutrients.keys())
    finally:
        rows.close()
    if not foods:
        raise CiqualFormatError("il file non ha nemmeno un alimento con codice e nome")
    return CiqualFile(
        foods=list(foods.values()),
        with_value=dict(with_value),
        unreadable=dict(unreadable),
        absent=columns.absent,
        unused=columns.unused,
        skipped_rows=skipped,
        duplicate_codes=duplicates,
    )
```

```python
`ciqual_foods` è la tabella CIQUAL caricata dal file dell'Anses (`app.cli.load_ciqual`):

from enum import StrEnum
from typing import Any
```

```python
"""La tabella CIQUAL nel database (S4, fetta 1): scriverla, contarla, cercarla.

I candidati di un ingrediente si trovano con `word_similarity` di `pg_trgm` sui nomi
francesi, una parola di ricerca alla volta. Non e5: in produzione la ricerca semantica è
spenta (`INSTALL_EMBEDDINGS=0`, spec §3), e i trigrammi fra italiano e francese non si
incontrano — per questo le parole francesi le scrive l'AI (`services/ciqual_match.py`).
Le tremila righe si leggono intere a ogni domanda: è meno di un millisecondo per riga,
e un indice non varrebbe la migrazione.
"""

from collections.abc import Sequence
from dataclasses import dataclass

from sqlalchemy import func, or_, select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.models.nutrition import CiqualFood
from app.domain.ciqual import CIQUAL_VERSION, CiqualRow

# Sotto questa somiglianza un alimento non è un candidato: l'AI sceglierebbe fra rumore.
CANDIDATE_MIN_SIMILARITY = 0.3
# Nella ricerca di Anagrafica si vuole di più: lì c'è anche il pezzo di nome esatto.
SEARCH_MIN_SIMILARITY = 0.4
UPSERT_CHUNK = 500


@dataclass(frozen=True)
class Candidate:
    code: str
    name_fr: str
    group_fr: str | None
    score: float


async def upsert_foods(
    session: AsyncSession, foods: Sequence[CiqualRow], version: str = CIQUAL_VERSION
) -> int:
    """Scrive o aggiorna per codice. Non cancella niente: un alimento che il file non ha
    più resta, perché un ingrediente può averlo scelto (`RESTRICT`)."""
    for start in range(0, len(foods), UPSERT_CHUNK):
        chunk = foods[start : start + UPSERT_CHUNK]
        statement = pg_insert(CiqualFood).values(
            [
                {
                    "code": food.code,
                    "name_fr": food.name_fr,
                    "group_fr": food.group_fr,
                    "nutrients": food.nutrients,
                    "version": version,
                }
                for food in chunk
            ]
        )
        await session.execute(
            statement.on_conflict_do_update(
                index_elements=[CiqualFood.code],
                set_={
                    "name_fr": statement.excluded.name_fr,
                    "group_fr": statement.excluded.group_fr,
                    "nutrients": statement.excluded.nutrients,
                    "version": statement.excluded.version,
                },
            )
        )
    return len(foods)


async def count_foods(session: AsyncSession) -> int:
    return (await session.execute(select(func.count()).select_from(CiqualFood))).scalar_one()


async def count_missing_from(session: AsyncSession, codes: set[str]) -> int:
    """Quanti alimenti nel database il file non ha."""
    return (
        await session.execute(
            select(func.count()).select_from(CiqualFood).where(CiqualFood.code.not_in(sorted(codes)))
        )
    ).scalar_one()


async def get_food(session: AsyncSession, code: str) -> CiqualFood | None:
    # `populate_existing`: dopo un caricamento (una INSERT … ON CONFLICT, che l'identity
    # map non vede) l'oggetto in memoria potrebbe essere quello vecchio
    return (
        await session.execute(
            select(CiqualFood)
            .where(CiqualFood.code == code)
            .execution_options(populate_existing=True)
        )
    ).scalar_one_or_none()


async def find_candidates(
    session: AsyncSession,
    terms: Sequence[str],
    limit: int,
    min_similarity: float = CANDIDATE_MIN_SIMILARITY,
) -> list[Candidate]:
    """I migliori `limit` alimenti per almeno una delle parole, ciascuno col suo
    punteggio migliore; a parità, per nome."""
    best: dict[str, Candidate] = {}
    for term in terms:
        score = func.word_similarity(term, CiqualFood.name_fr)
        rows = (
            await session.execute(
                select(CiqualFood.code, CiqualFood.name_fr, CiqualFood.group_fr, score.label("score"))
                .where(score >= min_similarity)
                .order_by(score.desc(), CiqualFood.name_fr)
                .limit(limit)
            )
        ).all()
        for row in rows:
            known = best.get(row.code)
            if known is None or row.score > known.score:
                best[row.code] = Candidate(row.code, row.name_fr, row.group_fr, float(row.score))
    ranked = sorted(best.values(), key=lambda candidate: (-candidate.score, candidate.name_fr))
    return ranked[:limit]


def _escape_like(text: str) -> str:
    return text.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")


async def search_foods(session: AsyncSession, query: str, limit: int) -> list[CiqualFood]:
    """La ricerca della correzione in Anagrafica: il codice esatto prima, poi il pezzo di
    nome e la somiglianza. `%` e `_` sono lettere, non jolly."""
    text = query.strip()
    if not text:
        return []
    score = func.word_similarity(text, CiqualFood.name_fr)
    exact = CiqualFood.code == text
    return list(
        (
            await session.execute(
                select(CiqualFood)
                .where(
                    or_(
                        exact,
                        CiqualFood.name_fr.ilike(f"%{_escape_like(text)}%", escape="\\"),
                        score >= SEARCH_MIN_SIMILARITY,
                    )
                )
                .order_by(exact.desc(), score.desc(), CiqualFood.name_fr)
                .limit(limit)
            )
        ).scalars()
    )
```

```python
    python -m app.cli.load_ciqual --dry-run        # legge, conta, stampa; non scrive
    python -m app.cli.load_ciqual                  # data/ciqual/ciqual-2025.xlsx
    python -m app.cli.load_ciqual <percorso.xlsx>  # un altro file

Il file è l'XLSX della scheda ufficiale (https://doi.org/10.57745/RDMHWY), messo nel
repository da Mattia: `data/` è montata su `/data` nei container (spec §4.1). La prova a
secco non apre nemmeno il database: si può lanciare ovunque, prima di tutto. Il
caricamento vero aggiorna per codice e non cancella niente; un file che non torna
(un'unità diversa, una colonna d'obbligo che manca) non scrive niente e dice perché.
"""

import asyncio
import sys
from pathlib import Path

from app.core.config import REPO_ROOT
from app.core.db import SessionLocal
from app.domain.ciqual import CIQUAL_NAMES, CIQUAL_URL, CIQUAL_VERSION, CiqualFormatError
from app.domain.nutrients import NUTRIENT_FIELDS
from app.repositories.ciqual import count_missing_from, upsert_foods
from app.services.ciqual_file import CiqualFile, read_ciqual

FLAG_DRY_RUN = "--dry-run"
DEFAULT_FILE = Path("ciqual") / "ciqual-2025.xlsx"
# fuori dal container il file sta nel repository; dentro, `data/` è montata su /data
CANDIDATE_FILES: tuple[Path, ...] = (REPO_ROOT / "data" / DEFAULT_FILE, Path("/data") / DEFAULT_FILE)

HOWTO_MISSING = (
    f"Non trovo la tabella CIQUAL (data/{DEFAULT_FILE.as_posix()}). Scaricala da {CIQUAL_URL} "
    "— il file «Table Ciqual 2025_FR_2025_11_03.xlsx» — e mettila in "
    f"data/{DEFAULT_FILE.as_posix()}, oppure passa il percorso del file."
)


def _default_file() -> Path | None:
    for candidate in CANDIDATE_FILES:
        if candidate.is_file():
            return candidate
    return None


def report_lines(file: CiqualFile, name: str) -> list[str]:
    lines = [f"{name}: {len(file.foods)} alimenti letti.", "Valori per nutriente:"]
    for key in CIQUAL_NAMES:
        if key in file.absent:
            continue
        field = NUTRIENT_FIELDS[key]
        line = f"  {field.label} ({field.unit}): {file.with_value.get(key, 0)} alimenti"
        bad = file.unreadable.get(key, 0)
        if bad:
            line += f", {bad} " + ("illeggibile" if bad == 1 else "illeggibili")
        lines.append(line)
    if file.absent:
        labels = ", ".join(NUTRIENT_FIELDS[key].label for key in file.absent)
        lines.append(f"Nel vocabolario ma non nel file: {labels}.")
    if file.unused:
        lines.append(f"Colonne non usate: {len(file.unused)}, per esempio «{file.unused[0]}».")
    if file.skipped_rows:
        lines.append(f"Righe senza codice o senza nome, saltate: {file.skipped_rows}.")
    if file.duplicate_codes:
        lines.append(f"Righe con un codice già letto, saltate: {file.duplicate_codes}.")
    return lines


async def main(argv: list[str]) -> int:
    dry_run = FLAG_DRY_RUN in argv
    rest = [arg for arg in argv if arg != FLAG_DRY_RUN]
    # La guardia esce con codice diverso da zero, non solo stampando: un refuso in uno
    # script che controlla l'exit code non deve passare per un successo.
    flags = [arg for arg in rest if arg.startswith("--")]
    if flags:
        print(f"argomento sconosciuto: {flags[0]}")
        return 2
    if len(rest) > 1:
        print(f"uso: python -m app.cli.load_ciqual [{FLAG_DRY_RUN}] [percorso.xlsx]")
        return 2
    if rest:
        path = Path(rest[0])
        if not path.is_file():
            print(f"Non trovo il file «{path}».")
            return 1
    else:
        found = _default_file()
        if found is None:
            print(HOWTO_MISSING)
            return 1
        path = found

    try:
        file = read_ciqual(path)
    except CiqualFormatError as exc:
        print(f"Il file non va: {exc}. Niente è stato scritto.")
        return 1
    for line in report_lines(file, path.name):
        print(line)
    if dry_run:
        print("Prova a secco: niente è stato scritto.")
        return 0

    async with SessionLocal() as session:
        written = await upsert_foods(session, file.foods)
        missing = await count_missing_from(session, {food.code for food in file.foods})
        await session.commit()
    print(f"{written} alimenti scritti in CIQUAL {CIQUAL_VERSION}.")
    if missing == 1:
        print("1 alimento già nel database non è nel file: resta com'è.")
    elif missing:
        print(f"{missing} alimenti già nel database non sono nel file: restano come sono.")
    return 0


if __name__ == "__main__":
    sys.exit(asyncio.run(main(sys.argv[1:])))
```

```python
"""Quale alimento CIQUAL dà i nutrienti a un ingrediente (S4, fetta 1).

L'unico posto che scrive `ingredient_nutrition`: la scelta a mano (Anagrafica, rotte di
`app/api/nutrition.py`) e quella dell'AI (`services/ciqual_match.py`). Non sta in
`registry.py` perché non tocca l'anagrafica — non rinomina, non sposta, non fonde — e
perché quel file lo cambiano altri piani della stessa notte (spec §4.16). Il rifiuto ha
la stessa forma di quelli dell'anagrafica: un codice e una frase da mostrare.

Tre stati (spec §4.5): nessuna riga = da decidere; `ciqual_code` NULL = «nessun alimento
adatto», deciso; un codice = quell'alimento. Una scelta a mano vince sempre: la scrive
anche sopra quella dell'AI, mentre l'AI scrive solo dove non c'è niente, e lo controlla
nella stessa INSERT (`ON CONFLICT DO NOTHING`). «Annulla la scelta» toglie la riga:
l'ingrediente torna da decidere, e l'AI lo riprenderà al giro dopo.
"""

import uuid
from dataclasses import dataclass
from enum import StrEnum

from sqlalchemy import delete, func, select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.models.ingredient import Ingredient
from app.db.models.nutrition import CiqualFood, IngredientNutrition, NutritionDecider
from app.domain.rules import IngredientKind
from app.repositories.ciqual import get_food

NON_FOOD_CODE = "non_food"
UNKNOWN_FOOD_CODE = "unknown_food"


class NutritionState(StrEnum):
    UNDECIDED = "undecided"
    NONE = "none"
    FOOD = "food"
    NON_FOOD = "non_food"


class NutritionRefusal(Exception):
    """Una scelta che non si può salvare così com'è, detta col suo perché."""

    def __init__(self, code: str, message: str) -> None:
        super().__init__(message)
        self.code = code
        self.message = message


@dataclass(frozen=True)
class NutritionView:
    state: NutritionState
    decided_by: str | None = None
    food: CiqualFood | None = None


async def _ingredient(session: AsyncSession, ingredient_id: uuid.UUID) -> Ingredient:
    ingredient = await session.get(Ingredient, ingredient_id)
    if ingredient is None:
        raise LookupError(f"nessun ingrediente {ingredient_id}")
    return ingredient


async def nutrition_of(session: AsyncSession, ingredient_id: uuid.UUID) -> NutritionView:
    ingredient = await _ingredient(session, ingredient_id)
    if ingredient.kind != IngredientKind.FOOD:
        return NutritionView(NutritionState.NON_FOOD)
    # le colonne e non l'oggetto: una INSERT … ON CONFLICT appena fatta non passa
    # dall'identity map, e un oggetto già in memoria sarebbe quello di prima
    row = (
        await session.execute(
            select(IngredientNutrition.ciqual_code, IngredientNutrition.decided_by).where(
                IngredientNutrition.ingredient_id == ingredient_id
            )
        )
    ).first()
    if row is None:
        return NutritionView(NutritionState.UNDECIDED)
    if row.ciqual_code is None:
        return NutritionView(NutritionState.NONE, row.decided_by)
    return NutritionView(NutritionState.FOOD, row.decided_by, await get_food(session, row.ciqual_code))


async def choose_food(
    session: AsyncSession, ingredient_id: uuid.UUID, code: str | None
) -> NutritionView:
    """La scelta a mano: un codice, o `None` per «nessun alimento adatto». Vince sempre."""
    ingredient = await _ingredient(session, ingredient_id)
    if ingredient.kind != IngredientKind.FOOD:
        raise NutritionRefusal(
            NON_FOOD_CODE,
            f"«{ingredient.display_name}» non è un alimento: non ha valori nutrizionali.",
        )
    if code is not None and await get_food(session, code) is None:
        raise NutritionRefusal(
            UNKNOWN_FOOD_CODE,
            "Questo alimento non è nella tabella CIQUAL caricata: cercane un altro.",
        )
    statement = pg_insert(IngredientNutrition).values(
        ingredient_id=ingredient_id,
        ciqual_code=code,
        decided_by=NutritionDecider.HUMAN,
        decided_at=func.now(),
    )
    await session.execute(
        statement.on_conflict_do_update(
            index_elements=[IngredientNutrition.ingredient_id],
            set_={
                "ciqual_code": statement.excluded.ciqual_code,
                "decided_by": statement.excluded.decided_by,
                "decided_at": statement.excluded.decided_at,
            },
        )
    )
    return await nutrition_of(session, ingredient_id)


async def forget_choice(session: AsyncSession, ingredient_id: uuid.UUID) -> NutritionView:
    """L'annullamento: la riga se ne va, e l'ingrediente torna da decidere."""
    await _ingredient(session, ingredient_id)
    await session.execute(
        delete(IngredientNutrition).where(IngredientNutrition.ingredient_id == ingredient_id)
    )
    return await nutrition_of(session, ingredient_id)


async def apply_ai_choice(
    session: AsyncSession, ingredient_id: uuid.UUID, code: str | None
) -> bool:
    """La scelta dell'AI, solo dove non c'è niente. `True` se l'ha scritta.

    Il controllo sta nella INSERT stessa: una scelta fatta a mano mentre il comando
    aspettava la risposta non si sovrascrive.
    """
    result = await session.execute(
        pg_insert(IngredientNutrition)
        .values(ingredient_id=ingredient_id, ciqual_code=code, decided_by=NutritionDecider.AI)
        .on_conflict_do_nothing(index_elements=[IngredientNutrition.ingredient_id])
    )
    return result.rowcount == 1
```

```python
"""I valori nutrizionali di un ingrediente in HTTP (S4, fetta 1).

Il server dice tutto quel che lo schermo deve mostrare: quali nutrienti, con che nome,
che unità, in che ordine, e quali sono «principali» (le otto righe dell'etichetta, che si
mostrano anche vuote). Il frontend non tiene una seconda copia del vocabolario.
"""

from collections.abc import Mapping
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field

from app.domain.ciqual import CODE_MAX_LENGTH
from app.domain.nutrients import MAIN_FIELDS, NUTRIENT_FIELDS


class CiqualFoodOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    code: str
    name_fr: str
    group_fr: str | None


class NutrientValueOut(BaseModel):
    key: str
    label: str
    unit: str
    main: bool
    # `None` solo per un principale che CIQUAL non dà: a video «—», mai zero
    value: float | None


class IngredientNutritionOut(BaseModel):
    state: Literal["undecided", "none", "food", "non_food"]
    decided_by: Literal["ai", "human"] | None
    food: CiqualFoodOut | None
    # per 100 g di parte edibile; vuoto se non c'è un alimento
    nutrients: list[NutrientValueOut]
    source: str
    citation: str


class NutritionChoiceIn(BaseModel):
    # obbligatorio, anche `null`: `null` vuol dire «nessun alimento adatto», che è una
    # scelta, non una dimenticanza
    ciqual_code: str | None = Field(max_length=CODE_MAX_LENGTH)


def nutrient_rows(values: Mapping[str, float] | None) -> list[NutrientValueOut]:
    """I principali sempre, gli altri se presenti, nell'ordine del vocabolario."""
    if values is None:
        return []
    rows = []
    for key, field in NUTRIENT_FIELDS.items():
        main = key in MAIN_FIELDS
        if main or key in values:
            rows.append(
                NutrientValueOut(
                    key=key, label=field.label, unit=field.unit, main=main, value=values.get(key)
                )
            )
    return rows
```

```python
"""I valori nutrizionali di un ingrediente, e la ricerca in CIQUAL (S4, fetta 1).

Rotte a sé, e non un campo della scheda dell'ingrediente (`IngredientDetailOut`): quella
la cambiano altri piani della stessa notte, e un campo obbligatorio in più costringerebbe
a riscrivere ogni oggetto di prova del frontend (spec §4.17). Il rifiuto è un 409 con
`code` e `detail`, la forma dei rifiuti dell'anagrafica: lo schermo lo legge con
`registryRefusal`.
"""

import uuid

from fastapi import APIRouter, Depends, HTTPException, Query, status
from fastapi.responses import JSONResponse
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.db import get_session
from app.core.security import require_session
from app.domain.ciqual import CIQUAL_CITATION, CIQUAL_SOURCE
from app.repositories.ciqual import search_foods
from app.schemas.nutrition import (
    CiqualFoodOut,
    IngredientNutritionOut,
    NutritionChoiceIn,
    nutrient_rows,
)
from app.services.ingredient_nutrition import (
    NutritionRefusal,
    NutritionView,
    choose_food,
    forget_choice,
    nutrition_of,
)

router = APIRouter(
    prefix="/api/v1/ingredients", tags=["nutrition"], dependencies=[Depends(require_session)]
)
ciqual_router = APIRouter(
    prefix="/api/v1/ciqual", tags=["nutrition"], dependencies=[Depends(require_session)]
)

_CONFLICT = {status.HTTP_409_CONFLICT: {"description": "rifiuto: `code` e `detail`"}}


def nutrition_out(view: NutritionView) -> IngredientNutritionOut:
    return IngredientNutritionOut(
        state=view.state.value,
        decided_by=view.decided_by,
        food=CiqualFoodOut.model_validate(view.food) if view.food is not None else None,
        nutrients=nutrient_rows(view.food.nutrients if view.food is not None else None),
        source=CIQUAL_SOURCE,
        citation=CIQUAL_CITATION,
    )


def _refusal(exc: NutritionRefusal) -> JSONResponse:
    return JSONResponse(
        {"detail": exc.message, "code": exc.code}, status_code=status.HTTP_409_CONFLICT
    )


def _missing(exc: LookupError) -> HTTPException:
    return HTTPException(status.HTTP_404_NOT_FOUND, "ingrediente inesistente")


@ciqual_router.get("/foods", response_model=list[CiqualFoodOut])
async def foods(
    q: str = Query(min_length=1, max_length=80),
    limit: int = Query(default=20, ge=1, le=50),
    session: AsyncSession = Depends(get_session),
) -> list[CiqualFoodOut]:
    return [CiqualFoodOut.model_validate(food) for food in await search_foods(session, q, limit)]


@router.get("/{ingredient_id}/nutrition", response_model=IngredientNutritionOut)
async def read_nutrition(
    ingredient_id: uuid.UUID, session: AsyncSession = Depends(get_session)
) -> IngredientNutritionOut:
    try:
        return nutrition_out(await nutrition_of(session, ingredient_id))
    except LookupError as exc:
        raise _missing(exc) from exc


@router.put(
    "/{ingredient_id}/nutrition", response_model=IngredientNutritionOut, responses=_CONFLICT
)
async def choose_nutrition(
    ingredient_id: uuid.UUID,
    payload: NutritionChoiceIn,
    session: AsyncSession = Depends(get_session),
) -> IngredientNutritionOut | JSONResponse:
    try:
        view = await choose_food(session, ingredient_id, payload.ciqual_code)
    except LookupError as exc:
        await session.rollback()
        raise _missing(exc) from exc
    except NutritionRefusal as exc:
        await session.rollback()
        return _refusal(exc)
    out = nutrition_out(view)
    await session.commit()
    return out


@router.delete("/{ingredient_id}/nutrition", response_model=IngredientNutritionOut)
async def forget_nutrition(
    ingredient_id: uuid.UUID, session: AsyncSession = Depends(get_session)
) -> IngredientNutritionOut:
    try:
        view = await forget_choice(session, ingredient_id)
    except LookupError as exc:
        await session.rollback()
        raise _missing(exc) from exc
    out = nutrition_out(view)
    await session.commit()
    return out
```

```python
"""Una chiamata all'AI che si registra sempre, e il conto di un giro (S4).

`complete_recorded` è `complete_json` più la riga in `llm_calls` — anche per la chiamata
fallita, come fanno `unit_forms.py` e `decide_emoji` — e più la somma della spesa in uno
`Spend`, se chi chiama ne passa uno: il pilota la stampa (spec §4.19). Un posto solo, perché
i comandi di S4 e il pilota non ne tengano tre copie. Una chiamata fallita si conta senza
costo: di una chiamata fallita non sappiamo se ci è stata addebitata, e zero sarebbe
un'affermazione (la regola dei nutrienti, e di `LlmCall`).
"""

from dataclasses import dataclass
from typing import Any

import httpx
from sqlalchemy.ext.asyncio import AsyncSession

from app.repositories.llm_calls import record_llm_call
from app.services.llm import LlmCallSite, LlmUnavailable, LlmUsage, complete_json


@dataclass
class Spend:
    calls: int = 0
    cost_usd: float = 0.0
    # chiamate senza un costo dichiarato: le fallite, e quelle senza `usage.cost`
    unpriced: int = 0

    def add(self, usage: LlmUsage) -> None:
        self.calls += 1
        if usage.cost_usd is None:
            self.unpriced += 1
        else:
            self.cost_usd += usage.cost_usd


async def complete_recorded(
    session: AsyncSession,
    *,
    call_site: LlmCallSite,
    system: str,
    user: str,
    schema: dict[str, Any],
    schema_name: str,
    max_tokens: int,
    client: httpx.AsyncClient | None = None,
    spend: Spend | None = None,
) -> dict[str, Any]:
    """La risposta, o `LlmUnavailable` — in tutti e due i casi dopo averla registrata.
    Il commit resta di chi chiama, come in `record_llm_call`."""
    try:
        esito = await complete_json(
            call_site=call_site,
            system=system,
            user=user,
            schema=schema,
            schema_name=schema_name,
            max_tokens=max_tokens,
            client=client,
        )
    except LlmUnavailable:
        await record_llm_call(session, call_site=call_site, usage=LlmUsage(), ok=False)
        if spend is not None:
            spend.add(LlmUsage())
        raise
    await record_llm_call(session, call_site=call_site, usage=esito.usage, ok=True)
    if spend is not None:
        spend.add(esito.usage)
    return esito.data
```

```python
Due passi, perché in produzione la ricerca semantica è spenta e i trigrammi fra italiano e
francese non si incontrano («pomodoro» / «tomate») — spec §4.9–4.12:

1. **le parole di ricerca**: a lotti di `TERMS_BATCH` nomi italiani, l'AI scrive da una a
   tre parole in francese, come le scriverebbe CIQUAL (sezione `ciqual_terms`);
2. **la scelta**: con quelle parole e il nome italiano, `pg_trgm` trova i candidati veri
   nella tabella (`find_candidates`), e l'AI sceglie il codice di uno dei **suoi**
   candidati, o `null` se nessuno è quell'ingrediente (sezione `ciqual_match`).

L'AI non può inventare un codice: uno che non è fra i candidati di quell'ingrediente non
si applica. Come in `decide_emoji`, i nomi si numerano e la risposta riporta numero e
nome: in un lotto un modello piccolo può scivolare di una riga, e il nome lo fa vedere.
Lo schema stretto è una forma, non una verifica: la verifica è qui.

Un ingrediente per cui la ricerca non trova nemmeno un candidato è «nessun alimento
adatto», senza chiedere la scelta; lo stesso per `null` dall'AI. Si scrive, e il giro dopo
non lo richiede (deciso da Mattia il 2026-10-13): «Annulla la scelta» in Anagrafica lo
rimette da decidere.

`match_names` lavora sui nomi e non scrive: la usa anche il pilota. `decide_ciqual` è il
giro sugli ingredienti, e scrive con `apply_ai_choice`, solo dove non c'è niente.

@dataclass(frozen=True)
class NameToMatch:
    name: str
    category: str


@dataclass(frozen=True)
class Matched:
    # None = «nessun alimento adatto»
    code: str | None
    # quanti candidati ha visto l'AI: 0 se la ricerca non ne ha trovati
    candidates: int


@dataclass(frozen=True)
class MatchBatch:
    # per nome, solo quelli decisi: un nome che manca è da decidere
    decided: dict[str, Matched]
    refused: int = 0
    unavailable: str | None = None


def _numbered(answer: object, asked: dict[int, Any], answered: set[int]) -> int | None:
    """Il numero di una risposta, se è uno di quelli chiesti e non già risposto."""
    if not isinstance(answer, dict):
        return None
    n = answer.get("n")
    if type(n) is not int or n not in asked or n in answered:
        return None
    return n


def _same_name(answer: dict, name: str) -> bool:
    return str(answer.get("nome") or "").strip().casefold() == name.casefold()


async def _ask_terms(
    session: AsyncSession,
    chunk: Sequence[NameToMatch],
    client: httpx.AsyncClient | None,
    spend: Spend | None,
) -> tuple[dict[str, list[str]], int]:
    asked = dict(enumerate(chunk, start=1))
    question = {
        "ingredienti": [
            {"n": n, "nome": item.name, "reparto": item.category} for n, item in asked.items()
        ]
    }
    data = await complete_recorded(
        session,
        call_site=LlmCallSite.CIQUAL_TERMS,
        system=TERMS_SYSTEM_PROMPT,
        user=json.dumps(question, ensure_ascii=False),
        schema=TERMS_SCHEMA,
        schema_name="termini_ciqual",
        max_tokens=TERMS_MAX_TOKENS,
        client=client,
        spend=spend,
    )
    terms: dict[str, list[str]] = {}
    refused = 0
    answered: set[int] = set()
    for answer in data.get("ingredienti") or []:
        n = _numbered(answer, asked, answered)
        if n is None or not _same_name(answer, asked[n].name):
            refused += 1
            continue
        answered.add(n)
        words = [
            word.strip()
            for word in answer.get("termini") or []
            if isinstance(word, str) and word.strip() and len(word.strip()) <= TERM_MAX_LENGTH
        ][:MAX_TERMS]
        if not words:
            refused += 1
            continue
        terms[asked[n].name] = words
    return terms, refused


async def _ask_choices(
    session: AsyncSession,
    group: Sequence[tuple[NameToMatch, list[Candidate]]],
    client: httpx.AsyncClient | None,
    spend: Spend | None,
) -> tuple[dict[str, Matched], int]:
    asked = dict(enumerate(group, start=1))
    question = {
        "ingredienti": [
            {
                "n": n,
                "nome": item.name,
                "candidati": [
                    {"codice": c.code, "nome": c.name_fr, "gruppo": c.group_fr} for c in candidates
                ],
            }
            for n, (item, candidates) in asked.items()
        ]
    }
    data = await complete_recorded(
        session,
        call_site=LlmCallSite.CIQUAL_MATCH,
        system=CHOICE_SYSTEM_PROMPT,
        user=json.dumps(question, ensure_ascii=False),
        schema=CHOICE_SCHEMA,
        schema_name="scelte_ciqual",
        max_tokens=CHOICE_MAX_TOKENS,
        client=client,
        spend=spend,
    )
    chosen: dict[str, Matched] = {}
    refused = 0
    answered: set[int] = set()
    for answer in data.get("scelte") or []:
        n = _numbered(answer, asked, answered)
        if n is None or not _same_name(answer, asked[n][0].name):
            refused += 1
            continue
        answered.add(n)
        item, candidates = asked[n]
        code = answer.get("codice")
        if code is not None:
            code = code.strip() if isinstance(code, str) else None
            if code not in {candidate.code for candidate in candidates}:
                refused += 1
                continue
        chosen[item.name] = Matched(code=code, candidates=len(candidates))
    return chosen, refused


async def match_names(
    session: AsyncSession,
    names: Sequence[NameToMatch],
    client: httpx.AsyncClient | None = None,
    spend: Spend | None = None,
) -> MatchBatch:
    """Abbina i nomi, a lotti, senza scrivere niente. Al primo guasto dell'AI si ferma e
    torna quel che ha già deciso: chiedere oltre sarebbe pagare per sapere che è giù."""
    decided: dict[str, Matched] = {}
    refused = 0
    for start in range(0, len(names), TERMS_BATCH):
        chunk = names[start : start + TERMS_BATCH]
        try:
            terms, bad = await _ask_terms(session, chunk, client, spend)
        except LlmUnavailable as exc:
            return MatchBatch(decided, refused, str(exc))
        refused += bad
        with_candidates: list[tuple[NameToMatch, list[Candidate]]] = []
        for item in chunk:
            if item.name not in terms:
                continue
            candidates = await find_candidates(
                session, [*terms[item.name], item.name], limit=CANDIDATES
            )
            if not candidates:
                decided[item.name] = Matched(code=None, candidates=0)
                continue
            with_candidates.append((item, candidates))
        for group_start in range(0, len(with_candidates), CHOICE_BATCH):
            group = with_candidates[group_start : group_start + CHOICE_BATCH]
            try:
                chosen, bad = await _ask_choices(session, group, client, spend)
            except LlmUnavailable as exc:
                return MatchBatch(decided, refused, str(exc))
            refused += bad
            decided.update(chosen)
    return MatchBatch(decided, refused, None)


@dataclass(frozen=True)
class CiqualRun:
    """Quel che un lancio ha fatto, e quel che resta."""

    matched: int = 0
    none: int = 0
    refused: int = 0
    # gli ingredienti alimentari ancora da decidere alla fine, non solo quelli del
    # `--limit`: è la riga che dice a Mattia se rilanciare
    pending: int = 0
    unavailable: str | None = None
    asked: int = 0


def _pending_ingredients():
    return (
        select(Ingredient.id, Ingredient.name, Ingredient.category)
        .outerjoin(IngredientNutrition, IngredientNutrition.ingredient_id == Ingredient.id)
        .where(IngredientNutrition.ingredient_id.is_(None), Ingredient.kind == IngredientKind.FOOD)
    )


async def count_pending(session: AsyncSession) -> int:
    return (
        await session.execute(select(func.count()).select_from(_pending_ingredients().subquery()))
    ).scalar_one()


async def decide_ciqual(
    session: AsyncSession,
    client: httpx.AsyncClient | None = None,
    limit: int | None = None,
    after_batch: Callable[[], Awaitable[None]] | None = None,
    batch_size: int = TERMS_BATCH,
) -> CiqualRun:
    """Abbina gli ingredienti alimentari da decidere, i primi `limit` per nome.

    Non fa commit: lo fa `after_batch`, se c'è, dopo ogni lotto (il comando passa
    `session.commit`). Al primo guasto dell'AI si ferma, dopo aver scritto quel che il
    lotto aveva già deciso.
    """
    statement = _pending_ingredients().order_by(Ingredient.name)
    if limit is not None:
        statement = statement.limit(limit)
    rows = (await session.execute(statement)).all()
    matched = none = refused = 0
    unavailable: str | None = None
    for start in range(0, len(rows), batch_size):
        chunk = rows[start : start + batch_size]
        by_name = {row.name: row.id for row in chunk}
        result = await match_names(
            session, [NameToMatch(row.name, row.category) for row in chunk], client=client
        )
        refused += result.refused
        for name, decision in result.decided.items():
            if await apply_ai_choice(session, by_name[name], decision.code):
                if decision.code is None:
                    none += 1
                else:
                    matched += 1
        await session.flush()
        if after_batch is not None:
            await after_batch()
        if result.unavailable is not None:
            unavailable = result.unavailable
            break
    return CiqualRun(
        matched=matched,
        none=none,
        refused=refused,
        pending=await count_pending(session),
        unavailable=unavailable,
        asked=len(rows),
    )
```

```python
"""Il pilota di S4: Gemma basta? (spec §4.18–4.19, decisione 3 di Mattia del 2026-10-13).

Chiede all'AI i casi di `backend/app/data/s4_pilota.json` con gli stessi servizi del lancio
vero (`match_names`), e li confronta con le risposte note. Non scrive niente sugli
ingredienti: registra solo le chiamate in `llm_calls`, come ogni chiamata.

Un abbinamento atteso è un'espressione regolare sul nome francese normalizzato, non un
codice: i codici del 2025 non li ha visti chi ha scritto i casi (spec §3). Per lo stesso
motivo un caso la cui espressione non trova **nessun** alimento nella tabella caricata è
«da rivedere»: non si chiede all'AI e non entra nel conto — è il caso, non l'AI, a essere
sbagliato. La soglia (90%) dice se si può lanciare su tutto il catalogo; non blocca
niente: decide Mattia.
"""

import json
import re
from collections.abc import Sequence
from dataclasses import dataclass
from enum import StrEnum
from pathlib import Path

import httpx
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.models.nutrition import CiqualFood
from app.domain.ciqual import normalize_name
from app.services.ai_spend import Spend
from app.services.ciqual_match import NameToMatch, match_names

PILOT_FILE = Path(__file__).resolve().parent.parent / "data" / "s4_pilota.json"
MATCH_THRESHOLD = 0.9


@dataclass(frozen=True)
class MatchCase:
    ingredient: str
    category: str
    # espressione regolare sul nome normalizzato; None = «nessun alimento adatto»
    expected: str | None


class Verdict(StrEnum):
    RIGHT = "right"
    WRONG = "wrong"
    UNANSWERED = "unanswered"
    REVIEW = "review"


@dataclass(frozen=True)
class MatchOutcome:
    case: MatchCase
    verdict: Verdict
    code: str | None = None
    name: str | None = None


@dataclass(frozen=True)
class PilotCases:
    matches: list[MatchCase]


def load_cases(path: Path = PILOT_FILE) -> PilotCases:
    """I casi del file. Un'espressione rotta solleva `re.error` subito, non a metà giro."""
    data = json.loads(path.read_text(encoding="utf-8"))
    matches = []
    for item in data.get("abbinamenti", []):
        expected = item.get("atteso")
        if expected is not None:
            re.compile(expected)
        matches.append(MatchCase(str(item["ingrediente"]), str(item["reparto"]), expected))
    return PilotCases(matches=matches)


async def run_match_pilot(
    session: AsyncSession,
    cases: Sequence[MatchCase],
    client: httpx.AsyncClient | None = None,
    spend: Spend | None = None,
) -> tuple[list[MatchOutcome], str | None]:
    names = {
        code: name
        for code, name in (await session.execute(select(CiqualFood.code, CiqualFood.name_fr))).all()
    }
    plain = [normalize_name(name) for name in names.values()]
    to_review = {
        case.ingredient
        for case in cases
        if case.expected is not None and not any(re.search(case.expected, name) for name in plain)
    }
    asked = [NameToMatch(case.ingredient, case.category) for case in cases if case.ingredient not in to_review]
    result = await match_names(session, asked, client=client, spend=spend)

    outcomes = []
    for case in cases:
        if case.ingredient in to_review:
            outcomes.append(MatchOutcome(case, Verdict.REVIEW))
            continue
        matched = result.decided.get(case.ingredient)
        if matched is None:
            outcomes.append(MatchOutcome(case, Verdict.UNANSWERED))
            continue
        name = names.get(matched.code) if matched.code is not None else None
        if case.expected is None:
            right = matched.code is None
        else:
            right = name is not None and re.search(case.expected, normalize_name(name)) is not None
        outcomes.append(
            MatchOutcome(case, Verdict.RIGHT if right else Verdict.WRONG, matched.code, name)
        )
    return outcomes, result.unavailable


def score(outcomes: Sequence[MatchOutcome]) -> tuple[int, int]:
    """Giusti e contati: i casi da rivedere non contano."""
    counted = [outcome for outcome in outcomes if outcome.verdict != Verdict.REVIEW]
    return sum(outcome.verdict == Verdict.RIGHT for outcome in counted), len(counted)


def passes(right: int, counted: int, threshold: float) -> bool:
    return counted > 0 and right / counted >= threshold


def match_report(outcomes: Sequence[MatchOutcome]) -> list[str]:
    right, counted = score(outcomes)
    if counted == 0:
        lines = ["Abbinamenti: nessun caso da contare: i casi vanno rivisti."]
    else:
        verdict = "bastano" if passes(right, counted, MATCH_THRESHOLD) else "non bastano"
        lines = [
            f"Abbinamenti: {right} giusti su {counted} ({round(100 * right / counted)}%): "
            f"{verdict} (soglia {round(100 * MATCH_THRESHOLD)}%)."
        ]
    for outcome in outcomes:
        ingredient = outcome.case.ingredient
        expected = outcome.case.expected or "nessun alimento"
        if outcome.verdict == Verdict.WRONG and outcome.code is None:
            lines.append(f"  ✗ «{ingredient}»: nessun alimento scelto; atteso {expected}")
        elif outcome.verdict == Verdict.WRONG:
            lines.append(f"  ✗ «{ingredient}»: scelto «{outcome.name}» ({outcome.code}); atteso {expected}")
        elif outcome.verdict == Verdict.UNANSWERED:
            lines.append(f"  – «{ingredient}»: nessuna risposta verificabile dall'AI")
        elif outcome.verdict == Verdict.REVIEW:
            lines.append(
                f"  ? «{ingredient}»: nessun alimento della tabella corrisponde a {expected}: "
                "il caso va rivisto"
            )
    return lines


def spend_line(spend: Spend) -> str:
    cost = f"{spend.cost_usd:.4f}".replace(".", ",")
    calls = "chiamata" if spend.calls == 1 else "chiamate"
    line = f"Spesa del pilota: {cost} $ in {spend.calls} {calls}"
    if spend.unpriced:
        line += f", {spend.unpriced} senza costo dichiarato"
    return line + "."


def final_line(passed: bool) -> str:
    if passed:
        return "Il pilota passa: si può lanciare l'AI su tutto il catalogo."
    return (
        "Il pilota non passa: prima del lancio su tutto il catalogo serve un modello più "
        "forte (spec di S4, §9)."
    )
```

```python
"""Il pilota di S4: quanti casi con la risposta nota Gemma azzecca, e quanto costa.

    python -m app.cli.s4_pilot
    python -m app.cli.s4_pilot --casi <percorso.json>

Dopo `load_ciqual`, prima di `decide_ciqual`. Non scrive niente sugli ingredienti; le
chiamate si registrano in `llm_calls` come tutte. Se non passa, la spec di S4 al §9 dice
cosa servirebbe.
"""

import asyncio
import re
import sys
from pathlib import Path

from app.cli.decide_ciqual import EMPTY_TABLE
from app.core.db import SessionLocal
from app.domain.ciqual import CIQUAL_SOURCE
from app.repositories.ciqual import count_foods
from app.services.ai_spend import Spend
from app.services.s4_pilot import (
    MATCH_THRESHOLD,
    PILOT_FILE,
    final_line,
    load_cases,
    match_report,
    passes,
    run_match_pilot,
    score,
    spend_line,
)

FLAG_CASES = "--casi"


async def main(argv: list[str]) -> int:
    path = PILOT_FILE
    if argv:
        if len(argv) != 2 or argv[0] != FLAG_CASES:
            print(f"uso: python -m app.cli.s4_pilot [{FLAG_CASES} percorso.json]")
            return 2
        path = Path(argv[1])
    try:
        cases = load_cases(path)
    except (OSError, ValueError, KeyError, TypeError, re.error) as exc:
        print(f"I casi del pilota non si leggono ({exc}).")
        return 1

    async with SessionLocal() as session:
        if await count_foods(session) == 0:
            print(EMPTY_TABLE)
            return 1
        spend = Spend()
        outcomes, unavailable = await run_match_pilot(session, cases.matches, spend=spend)
        await session.commit()  # le chiamate in `llm_calls`

    if unavailable is not None:
        print(f"il pilota non si è potuto fare: l'AI non ha risposto ({unavailable}).")
        print(spend_line(spend))
        return 1
    print(f"Pilota S4 su {CIQUAL_SOURCE}: {len(cases.matches)} abbinamenti.")
    for line in match_report(outcomes):
        print(line)
    print(spend_line(spend))
    right, counted = score(outcomes)
    print(final_line(passes(right, counted, MATCH_THRESHOLD)))
    return 0


if __name__ == "__main__":
    sys.exit(asyncio.run(main(sys.argv[1:])))
```

```ts
/** Un nutriente come lo manda il server (S4): nome, unità, e se è una delle otto righe
 * dell'etichetta, che si mostrano sempre. `value` è `null` solo per un principale che la
 * fonte non dà: a video «—», mai zero (CLAUDE.md, «missing nutrients stay missing»). */
export type NutrientValue = {
  key: string;
  label: string;
  unit: string;
  main: boolean;
  value: number | null;
};

/** Una riga della tabella: il nutriente, e una nota sotto il valore se serve (la fetta 2
 * ci scrive «su 3 righe di 4»). */
export type NutrientRow = NutrientValue & { note?: string };

/** Il numero all'italiana: kcal senza decimali, il resto con uno, due sotto l'unità, e
 * senza il punto delle migliaia (che in una tabella stretta si legge come un decimale). */
export function formatNutrient(value: number, unit: string): string {
  const digits = unit === "kcal" ? 0 : value !== 0 && Math.abs(value) < 1 ? 2 : 1;
  const number = value.toLocaleString("it-IT", { maximumFractionDigits: digits, useGrouping: false });
  return `${number} ${unit}`;
}
```

```tsx
import { useState, type ReactNode } from "react";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { NutrientTable } from "../../components/NutrientTable";
import { Alert } from "../../components/ui/Alert";
import { Button } from "../../components/ui/Button";
import { Card } from "../../components/ui/Card";
import { SectionHeading } from "../../components/ui/SectionHeading";
import { CiqualPicker } from "./CiqualPicker";
import { decidedText, fetchNutrition, forgetFood, nutritionKey, type IngredientNutrition } from "./nutrition";

/** «Valori nutrizionali» nella scheda di un alimento in Anagrafica (S4, fetta 1).
 *
 * Legge la sua rotta, non la scheda: così la scheda non cambia forma (spec §4.17). Una
 * lettura fallita non è un avviso (`role="alert"`) e il suo pulsante non si chiama
 * «Riprova»: la scheda ha già i suoi, e due con lo stesso nome non si distinguerebbero. */
export function NutritionSection({ ingredientId }: { ingredientId: string }) {
  const queryClient = useQueryClient();
  const { data, isLoading, isError, refetch } = useQuery({
    queryKey: nutritionKey(ingredientId),
    queryFn: () => fetchNutrition(ingredientId),
  });
  const [picking, setPicking] = useState(false);
  const [note, setNote] = useState<string | null>(null);
  const forget = useMutation({
    mutationFn: () => forgetFood(ingredientId),
    onSuccess: (next) => {
      queryClient.setQueryData(nutritionKey(ingredientId), next);
      setNote("Scelta annullata: l'AI lo abbinerà al prossimo giro.");
    },
  });

  function pick() {
    setNote(null);
    forget.reset();
    setPicking(true);
  }

  let body: ReactNode;
  if (isLoading) {
    body = <p className="text-sm text-ink-soft">Carico i valori nutrizionali…</p>;
  } else if (isError || !data) {
    body = (
      <div className="flex flex-col items-start gap-2">
        <p className="text-sm text-ink-soft">Non sono riuscito a leggere i valori nutrizionali.</p>
        <Button variant="secondary" onClick={() => void refetch()}>
          Riprova a leggerli
        </Button>
      </div>
    );
  } else if (picking) {
    body = (
      <CiqualPicker
        ingredientId={ingredientId}
        current={data.food?.code ?? null}
        onDone={() => setPicking(false)}
      />
    );
  } else {
    body = (
      <Decision
        data={data}
        note={note}
        onPick={pick}
        onForget={() => forget.mutate()}
        forgetting={forget.isPending}
        forgetFailed={forget.isError}
      />
    );
  }

  return (
    <section>
      <SectionHeading>Valori nutrizionali</SectionHeading>
      <Card className="flex flex-col gap-3">
        {body}
        {/* la citazione che la licenza di CIQUAL chiede accanto a ogni riuso */}
        <p className="text-xs text-ink-faint">
          Fonte: Anses, Table de composition nutritionnelle des aliments Ciqual 2025.
        </p>
      </Card>
    </section>
  );
}

function Decision({
  data,
  note,
  onPick,
  onForget,
  forgetting,
  forgetFailed,
}: {
  data: IngredientNutrition;
  note: string | null;
  onPick: () => void;
  onForget: () => void;
  forgetting: boolean;
  forgetFailed: boolean;
}) {
  if (data.state === "undecided") {
    return (
      <div className="flex flex-col items-start gap-2">
        {note && (
          <p role="status" className="text-sm font-medium text-brand">
            {note}
          </p>
        )}
        <p className="text-sm">
          Non ancora abbinato a un alimento della tabella CIQUAL: lo farà l'AI al prossimo giro, oppure
          sceglilo tu.
        </p>
        <Button variant="secondary" onClick={onPick}>
          Scegli l'alimento
        </Button>
      </div>
    );
  }
  // una risposta che non è nessuno dei due stati qui sotto (`non_food`, o un corpo
  // inatteso) non disegna niente: la scheda non mostra la sezione a una voce non alimentare
  if (data.state !== "food" && data.state !== "none") return null;
  const food = data.state === "food" ? data.food : null;
  return (
    <>
      <div>
        <p className="font-medium">{food ? food.name_fr : "Nessun alimento adatto"}</p>
        <p className="text-xs text-ink-soft">
          {food
            ? `${data.source} · ${food.code} · ${decidedText(data.decided_by)}`
            : `${data.source} · ${decidedText(data.decided_by)}`}
        </p>
      </div>
      {food && <NutrientTable caption="Per 100 g" rows={data.nutrients ?? []} />}
      <div className="flex flex-col items-start gap-2">
        <Button variant="secondary" onClick={onPick}>
          Cambia alimento
        </Button>
        <Button variant="ghost" busy={forgetting} onClick={onForget}>
          Annulla la scelta
        </Button>
      </div>
      {forgetFailed && <Alert>Non sono riuscito ad annullare la scelta. Riprova.</Alert>}
    </>
  );
}
```
