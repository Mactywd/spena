# S4, fetta 2 — I grammi delle dosi e i nutrienti di una ricetta: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ogni dose di una ricetta che non è già in grammi o in litri («1 spicchio», «2 cucchiai», «2» uova) ha il suo peso in grammi per ingrediente × unità canonica, deciso dall'AI e corretto in Anagrafica; e una funzione pura somma i nutrienti di una ricetta con la copertura dichiarata — quali righe sono fuori dal conto, e perché — che il dettaglio della ricetta mostra a richiesta e P1 e P2 leggeranno.

**Architecture:** un modulo puro (`backend/app/domain/recipe_nutrition.py`) classifica un'unità (massa, volume, o da pesare per coppia; «pezzo» per la dose senza unità), conosce le densità, pesa una riga e somma una ricetta. `ingredient_unit_grams` (migrazione `0017`, `UNIQUE NULLS NOT DISTINCT`) tiene i grammi per coppia; `services/unit_grams.py` trova le coppie che le ricette usano, le scrive (a mano e dall'AI, con `decide_grams`) e le mostra; `services/recipe_nutrition.py` legge le righe di una ricetta e chiama la funzione pura. Le rotte stanno in `api/nutrition.py` (nato con la fetta 1): i pesi entrano nella risposta dei valori di un ingrediente, e una rotta nuova dà i nutrienti di una ricetta. Il pilota della fetta 1 impara 20 pesi. A video: «Pesi per unità» in Anagrafica, e «Valori nutrizionali» chiuso in fondo al dettaglio della ricetta.

**Tech Stack:** FastAPI, SQLAlchemy async, Alembic, pytest su Postgres vero (Postgres 16 per `NULLS NOT DISTINCT`); OpenRouter tramite `services/ai_spend.py` (`complete_recorded`, fetta 1), provato con i finti di `backend/tests/llm_fakes.py`; React 19, TypeScript, Tailwind 4, TanStack Query 5, Vitest + Testing Library (jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-s4-nutrienti-ingrediente-design.md` — §2 (le decisioni di Mattia del 2026-10-13), §4 (decisioni di Claude su delega, 18–19 per il pilota e 20–28 per questa fetta), §6 (comportamento e parole a video), §7, §10–§12. ## Obiettivo e contesto

La fetta 1 ha dato a ogni ingrediente i suoi nutrienti per 100 g. Una ricetta però non dice grammi: dice «1 spicchio», «2 cucchiai», «2» uova, «q.b.». Per sommare i nutrienti di una ricetta serve sapere quanto pesa una dose, e dirlo una volta per coppia ingrediente × unità canonica — è per questo che `units.canonical_id` esiste da D1. Questo piano costruisce i pesi, la funzione pura «nutrienti di una ricetta» con la copertura dichiarata (decisione 2 di Mattia: «q.b.» fuori, e detto), e il primo posto dove si vedono: il dettaglio della ricetta, a richiesta. È ciò che P1 (il pasto) e P2 (il NutriScore) leggeranno.

## Decisioni prese

Dalla spec, **decise da Mattia il 2026-10-13** (non si rimettono in discussione):

1. **Le righe «q.b.» restano fuori** dal conto dei nutrienti di una ricetta, e la copertura lo **dichiara**: quali righe mancano. Una stima per porzione dei grassi «q.b.» si deciderà nella spec di P2.
2. **Gemma, dopo un pilota**: il pilota della fetta 1 impara qui i suoi **20 pesi** (con i 30 abbinamenti fanno i ~50 casi), con le risposte note.
3. **La fetta 3** («Stima» sul prodotto) è decisa e rinviata (spec §8): in `next-steps.md` resta `tbd` «serve il piano» (Task 10).
4. **«nessun peso» dell'AI si scrive**, e il giro dopo non lo richiede; **la fusione perde i pesi del perdente** (spec §12, decise da Mattia il 2026-10-13).

Dalla spec §4, **decise da Claude su delega di Mattia** (reversibili):

5. (§4.20) **La tabella** `ingredient_unit_grams` (migrazione `0017`): `unit_id` FK `units` **`CASCADE`** e annullabile (NULL = il «pezzo»); `grams` `Numeric(8, 2)` annullabile (NULL = «nessun peso»), `CHECK grams > 0`; `decided_by`, `decided_at`; `UNIQUE NULLS NOT DISTINCT (ingredient_id, unit_id)`.
6. (§4.21) **Sempre sull'unità canonica** (`canonical_id`, o l'unità stessa); «pezzo»/«pezzi» valgono come la dose senza unità.
7. (§4.22) **Massa e volume non chiedono niente**: g, gr, grammo/i ×1; kg, chilo/i, chilogrammo/i ×1000; hg, etto/i ×100; mg ×0,001; ml, millilitro/i ×1; cl, centilitro/i ×10; dl, decilitro/i ×100; l, lt, litro/i ×1000, con **densità 1** salvo `olio…` 0,92, `miele…` 1,42, `sciroppo…` 1,33, `latte condensato…` 1,29 (sull'inizio del nome dell'ingrediente). La parola si riconosce sulla chiave o sul singolare dell'unità canonica.
8. (§4.23) **Le coppie da chiedere** sono quelle delle ricette (eliminate comprese), di un alimento, con una dose letta, su un'unità né di massa né di volume. L'AI le pesa a lotti da 40 (`decide_grams`, sezione `unit_grams`): numero, ingrediente, unità, un esempio di dose; grammi **netti della parte che si mangia** di una unità, o `null`. Si applica solo una risposta col numero e i nomi giusti e un peso fra 0 (escluso) e 5.000 g.
9. (§4.24) **La correzione in Anagrafica**: «Pesi per unità», una riga per coppia, «Correggi» con «Salva il peso», «Annulla il peso», «Lascia com'è». Una scelta `human` l'AI non la tocca; un'unità di massa o di volume si rifiuta (`measured_unit`).
10. (§4.25–4.26) **La funzione pura** `recipe_nutrition`: una riga si conta con dose letta + alimento CIQUAL + peso; altrimenti fuori col perché (`no_quantity`, `no_nutrients`, `no_weight`); per ogni nutriente su quante righe; a porzione se la ricetta dice le porzioni, altrimenti per tutta la ricetta.
11. (§4.27–4.28) **La rotta** `GET /api/v1/recipes/{id}/nutrition`, a sé; **a video** in fondo al dettaglio, dopo il procedimento, **chiuso** finché non lo si apre.

Scelte di questo piano, dove la spec non arrivava — **decise da Claude su delega di Mattia**:

12. **I pesi viaggiano nella risposta dei valori dell'ingrediente** (`IngredientNutritionOut.weights`), non in una rotta a sé: la sezione di Anagrafica legge una cosa sola, e la rilegge dopo ogni correzione. Le scritture hanno le loro rotte, `PUT|DELETE /api/v1/ingredients/{id}/unit-grams/{unit}`, dove `{unit}` è l'id dell'unità o la parola `pezzo`; rispondono con l'intera `IngredientNutritionOut`.
13. **Un peso fuori misura** scritto a mano (zero o meno, oltre i 5.000 g) è un rifiuto con la frase (`bad_grams`: «Un peso va da più di 0 a 5000 g: controlla il numero.»), non un 422 muto: il servizio lo controlla, e la rotta lo dice come gli altri rifiuti. Il campo del frontend non lascia mandare zero o meno, ma il server non si fida.
14. **La porzione la sceglie il server**: la risposta dice `basis` (`serving` o `recipe`) e per ogni nutriente un `value` solo, arrotondato (kcal all'intero, il resto a un decimale, due sotto l'unità: `round_nutrient`). Gli otto principali sempre (anche vuoti, «—»), gli altri se presenti, come nella scheda dell'ingrediente: la stessa `NutrientTable`.
15. **Il pannello della ricetta legge solo quando si apre** (`enabled: open`): il dettaglio non fa una chiamata in più a ogni apertura, e i test di oggi del dettaglio — che rispondono la ricetta a ogni chiamata — non la vedono.
16. **Dopo una correzione dei pesi o dell'alimento** in Anagrafica, il pannello della ricetta si rilegge (`invalidateQueries(["recipe-nutrition"])`).
17. **Il pilota dei pesi** confronta coll'intervallo del caso (`min`–`max` in grammi) e ha la soglia dell'80% (spec §4.19); un `null` dell'AI è sbagliato. Il pilota passa solo se passano tutti e due.

Una ricetta dice dosi, non grammi: «180 g», «2 cucchiai», «1 spicchio», «2» uova, «q.b.».
Qui sta come una dose diventa grammi, e come i grammi diventano nutrienti:

- **massa** (g, kg, hg, mg e le loro parole): i grammi si contano da sé;
- **volume** (ml, cl, dl, l e le loro parole): millilitri × densità — 1, dichiarata
  approssimata, salvo le eccezioni di `DENSITIES` sull'inizio del nome dell'ingrediente;
- **tutto il resto** (cucchiaio, spicchio, bicchiere, e la dose senza unità, il «pezzo»):
  il peso della coppia ingrediente × unità canonica, deciso una volta
  (`ingredient_unit_grams`).

Una riga si conta se ha una dose letta, un alimento CIQUAL e un peso; altrimenti è fuori
dal conto **col suo perché**: «q.b.» resta fuori, e la copertura lo dice (decisione di

su quante righe c'è (CLAUDE.md, «missing nutrients stay missing»).

from collections.abc import Mapping, Sequence
from dataclasses import dataclass

    "millilitro": Decimal("1"),
    "millilitri": Decimal("1"),
    "cl": Decimal("10"),
    "centilitro": Decimal("10"),
    "centilitri": Decimal("10"),

# «1 pezzo» e «1» sono la stessa dose: la coppia si scrive col «pezzo» (unità NULL)
PIECE_WORDS = frozenset({"pezzo", "pezzi"})
PIECE_LABEL = "pezzo"

# Le densità che si discostano da 1 abbastanza da contare, sull'inizio del nome
# dell'ingrediente. La prima che combacia vince: «latte condensato» prima di tutto.
DENSITIES: tuple[tuple[str, Decimal], ...] = (
    ("latte condensato", Decimal("1.29")),
    ("olio", Decimal("0.92")),
    ("miele", Decimal("1.42")),
    ("sciroppo", Decimal("1.33")),
)
DEFAULT_DENSITY = Decimal("1")

# Il peso più grande che un'unità di un ingrediente possa avere: un'anguria intera
# sta sotto. Oltre, è un errore di battitura o di modello.
GRAMS_MAX = Decimal("5000")

MissingReason = Literal["no_quantity", "no_nutrients", "no_weight"]


@dataclass(frozen=True)
class UnitKind:
    measure: Literal["mass", "volume", "pair"]
    # grammi (massa) o millilitri (volume) per unità; None per una coppia
    factor: Decimal | None
    # la coppia si scrive col «pezzo», cioè senza unità
    piece: bool


def _words(key: str | None, singular: str | None) -> list[str]:
    return [word.strip().lower() for word in (key, singular) if word]


def classify_unit(key: str | None, singular: str | None) -> UnitKind:
    """Che cosa vuol dire l'unità canonica di una dose. `key` None = dose senza unità."""
    words = _words(key, singular)
    if not words:
        return UnitKind("pair", None, True)
    for word in words:
        if word in GRAMS_PER_MASS_UNIT:
            return UnitKind("mass", GRAMS_PER_MASS_UNIT[word], False)
    for word in words:
        if word in ML_PER_VOLUME_UNIT:
            return UnitKind("volume", ML_PER_VOLUME_UNIT[word], False)
    if any(word in PIECE_WORDS for word in words):
        return UnitKind("pair", None, True)
    return UnitKind("pair", None, False)


def unit_label(key: str | None, singular: str | None) -> str:
    """Come si chiama a video l'unità di una coppia: «spicchio», «pezzo»."""
    if classify_unit(key, singular).piece:
        return PIECE_LABEL
    return (singular or key or PIECE_LABEL).strip()


def density_for(ingredient_name: str) -> Decimal:
    name = ingredient_name.strip().lower()
    for prefix, density in DENSITIES:
        if name.startswith(prefix):
            return density
    return DEFAULT_DENSITY


def line_grams(
    *, value: Decimal, kind: UnitKind, pair_grams: Decimal | None, ingredient_name: str
) -> Decimal | None:
    """I grammi di una dose, o None se manca il peso della coppia."""
    if kind.measure == "mass":
        return value * kind.factor
    if kind.measure == "volume":
        return value * kind.factor * density_for(ingredient_name)
    if pair_grams is None:
        return None
    return value * pair_grams


@dataclass(frozen=True)
class NutritionLine:
    ingredient_id: uuid.UUID
    ingredient_name: str
    quantity_text: str | None
    # la dose letta (`quantity_value`); None = «q.b.» o una dose che il parser non legge
    value: Decimal | None
    # chiave e singolare dell'unità **canonica**; None = dose senza unità
    unit_key: str | None
    unit_singular: str | None
    # i grammi decisi per la coppia; None se non decisi o decisi «nessun peso»
    pair_grams: Decimal | None
    # i valori per 100 g dell'alimento CIQUAL; None = nessun alimento
    per_100g: Mapping[str, float] | None


@dataclass(frozen=True)
class MissingLine:
    ingredient_id: uuid.UUID
    ingredient_name: str
    quantity_text: str | None
    reason: MissingReason
    # solo per `no_weight`: l'unità di cui manca il peso
    unit_label: str | None


@dataclass(frozen=True)
class RecipeNutrition:
    lines_total: int
    lines_counted: int
    # per tutta la ricetta, solo le chiavi che almeno una riga contata ha
    totals: dict[str, float]
    # chiave → quante righe contate hanno quel valore
    lines_with: dict[str, int]
    missing: tuple[MissingLine, ...]
    servings: int | None
    # i totali divisi per le porzioni; None se la ricetta non le dice
    per_serving: dict[str, float] | None


def recipe_nutrition(lines: Sequence[NutritionLine], servings: int | None) -> RecipeNutrition:
    totals: dict[str, float] = {}
    lines_with: Counter[str] = Counter()
    missing: list[MissingLine] = []
    counted = 0
    for line in lines:
        reason: MissingReason | None = None
        label: str | None = None
        grams: Decimal | None = None
        if line.value is None:
            reason = "no_quantity"
        elif line.per_100g is None:
            reason = "no_nutrients"
        else:
            kind = classify_unit(line.unit_key, line.unit_singular)
            grams = line_grams(
                value=line.value,
                kind=kind,
                pair_grams=line.pair_grams,
                ingredient_name=line.ingredient_name,
            )
            if grams is None:
                reason = "no_weight"
                label = unit_label(line.unit_key, line.unit_singular)
        if reason is not None:
            missing.append(
                MissingLine(line.ingredient_id, line.ingredient_name, line.quantity_text, reason, label)
            )
            continue
        counted += 1
        for key, per_100g in line.per_100g.items():
            totals[key] = totals.get(key, 0.0) + float(grams) * per_100g / 100
            lines_with[key] += 1
    per_serving = (
        {key: value / servings for key, value in totals.items()}
        if servings is not None and servings > 0
        else None
    )
    return RecipeNutrition(
        lines_total=len(lines),
        lines_counted=counted,
        totals=totals,
        lines_with=dict(lines_with),
        missing=tuple(missing),
        servings=servings,
        per_serving=per_serving,
    )


def round_nutrient(value: float, unit: str) -> float:
    """Come si dice un valore: kcal all'intero, il resto a un decimale, due sotto l'unità."""
    if unit == "kcal":
        return float(round(value))
    return round(value, 2 if abs(value) < 1 else 1)

"""I grammi per ingrediente × unità canonica (S4, fetta 2): quali coppie servono, chi le
scrive, come si mostrano.

Le coppie da pesare sono quelle che le ricette usano davvero — tutte, eliminate comprese,
perché una ricetta eliminata si ripristina — di un alimento, con una dose letta, su
un'unità che non è di massa né di volume (`classify_unit`). Sempre sull'unità canonica, e
«pezzo»/«pezzi» come la dose senza unità (spec §4.21–4.23).

L'unico posto che scrive `ingredient_unit_grams`: il peso a mano (Anagrafica, rotte di
`app/api/nutrition.py`) vince sempre e si scrive anche sopra quello dell'AI; l'AI scrive
solo dove non c'è niente, e lo controlla nella stessa INSERT. «Annulla il peso» toglie la
riga: la coppia torna da decidere. Il rifiuto ha la forma di quelli della fetta 1
(`NutritionRefusal`).
"""

import uuid
from collections.abc import Sequence
from dataclasses import dataclass
from decimal import Decimal
from typing import Literal

from sqlalchemy import delete, func, select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.orm import aliased

from app.db.models.ingredient import Ingredient
from app.db.models.nutrition import IngredientUnitGrams, NutritionDecider
from app.db.models.recipe import RecipeIngredient
from app.db.models.unit import Unit
from app.domain.recipe_nutrition import (
    GRAMS_MAX,
    PIECE_LABEL,
    UnitKind,
    classify_unit,
    unit_label,
)
from app.domain.rules import IngredientKind
from app.services.ingredient_nutrition import NON_FOOD_CODE, NutritionRefusal

MEASURED_UNIT_CODE = "measured_unit"
BAD_GRAMS_CODE = "bad_grams"


@dataclass(frozen=True)
class Pair:
    ingredient_id: uuid.UUID
    ingredient_name: str
    # l'unità canonica, o None per il pezzo
    unit_id: uuid.UUID | None
    unit_label: str
    # una dose com'è scritta in una ricetta: all'AI dice di che si parla
    example: str | None


@dataclass(frozen=True)
class Weight:
    # l'id dell'unità canonica, o «pezzo»: è anche il pezzo di indirizzo delle rotte
    unit: str
    unit_label: str
    grams: Decimal | None
    state: Literal["undecided", "decided", "none"]
    decided_by: str | None


def unit_param(unit_id: uuid.UUID | None) -> str:
    return PIECE_LABEL if unit_id is None else str(unit_id)


def _same_unit(unit_id: uuid.UUID | None):
    if unit_id is None:
        return IngredientUnitGrams.unit_id.is_(None)
    return IngredientUnitGrams.unit_id == unit_id


async def used_pairs(session: AsyncSession, ingredient_id: uuid.UUID | None = None) -> list[Pair]:
    seen = aliased(Unit)
    canonical = aliased(Unit)
    statement = (
        select(
            RecipeIngredient.ingredient_id,
            Ingredient.name,
            canonical.id,
            canonical.key,
            canonical.singular,
            func.min(RecipeIngredient.quantity_text),
        )
        .join(Ingredient, Ingredient.id == RecipeIngredient.ingredient_id)
        .outerjoin(seen, seen.id == RecipeIngredient.quantity_unit_id)
        .outerjoin(canonical, canonical.id == func.coalesce(seen.canonical_id, seen.id))
        .where(
            RecipeIngredient.quantity_value.is_not(None),
            Ingredient.kind == IngredientKind.FOOD,
        )
        .group_by(
            RecipeIngredient.ingredient_id, Ingredient.name, canonical.id, canonical.key, canonical.singular
        )
    )
    if ingredient_id is not None:
        statement = statement.where(RecipeIngredient.ingredient_id == ingredient_id)
    pairs: dict[tuple[uuid.UUID, uuid.UUID | None], Pair] = {}
    for ingredient, name, unit_id, key, singular, example in (await session.execute(statement)).all():
        kind = classify_unit(key, singular)
        if kind.measure != "pair":
            continue
        pair_unit = None if kind.piece else unit_id
        current = pairs.get((ingredient, pair_unit))
        if current is None or (example or "") < (current.example or ""):
            pairs[(ingredient, pair_unit)] = Pair(ingredient, name, pair_unit, unit_label(key, singular), example)
    return sorted(pairs.values(), key=lambda pair: (pair.ingredient_name, pair.unit_label))


async def decided_grams(
    session: AsyncSession, ingredient_ids: Sequence[uuid.UUID] | None = None
) -> dict[tuple[uuid.UUID, uuid.UUID | None], tuple[Decimal | None, str]]:
    """Le coppie decise: (ingrediente, unità) → (grammi o None, chi ha deciso)."""
    statement = select(
        IngredientUnitGrams.ingredient_id,
        IngredientUnitGrams.unit_id,
        IngredientUnitGrams.grams,
        IngredientUnitGrams.decided_by,
    )
    if ingredient_ids is not None:
        statement = statement.where(IngredientUnitGrams.ingredient_id.in_(list(ingredient_ids)))
    return {
        (row.ingredient_id, row.unit_id): (row.grams, row.decided_by)
        for row in (await session.execute(statement)).all()
    }


async def pending_pairs(session: AsyncSession, limit: int | None = None) -> list[Pair]:
    decided = await decided_grams(session)
    pending = [pair for pair in await used_pairs(session) if (pair.ingredient_id, pair.unit_id) not in decided]
    return pending if limit is None else pending[:limit]


async def count_pending_pairs(session: AsyncSession) -> int:
    return len(await pending_pairs(session))


async def weights_of(session: AsyncSession, ingredient_id: uuid.UUID) -> list[Weight]:
    """Le coppie di un ingrediente: quelle che le ricette usano, e quelle decise anche se
    nessuna ricetta le usa più (un peso scritto non sparisce di nascosto)."""
    decided = await decided_grams(session, [ingredient_id])
    labels: dict[uuid.UUID | None, str] = {
        pair.unit_id: pair.unit_label for pair in await used_pairs(session, ingredient_id)
    }
    extra = [unit_id for (_, unit_id) in decided if unit_id is not None and unit_id not in labels]
    if extra:
        for unit_id, key, singular in (
            await session.execute(select(Unit.id, Unit.key, Unit.singular).where(Unit.id.in_(extra)))
        ).all():
            labels[unit_id] = unit_label(key, singular)
    if (ingredient_id, None) in decided:
        labels.setdefault(None, PIECE_LABEL)
    weights = []
    for unit_id, label in labels.items():
        if (ingredient_id, unit_id) not in decided:
            weights.append(Weight(unit_param(unit_id), label, None, "undecided", None))
            continue
        grams, decided_by = decided[(ingredient_id, unit_id)]
        state = "none" if grams is None else "decided"
        weights.append(Weight(unit_param(unit_id), label, grams, state, decided_by))
    return sorted(weights, key=lambda weight: weight.unit_label)


async def resolve_pair_unit(
    session: AsyncSession, unit_id: uuid.UUID | None
) -> tuple[uuid.UUID | None, str, UnitKind]:
    """L'unità della coppia (canonica, o None per il pezzo), il suo nome e il suo tipo."""
    if unit_id is None:
        return None, PIECE_LABEL, classify_unit(None, None)
    unit = await session.get(Unit, unit_id)
    if unit is None:
        raise LookupError(f"nessuna unità {unit_id}")
    canonical = unit if unit.canonical_id is None else await session.get(Unit, unit.canonical_id)
    kind = classify_unit(canonical.key, canonical.singular)
    return (None if kind.piece else canonical.id), unit_label(canonical.key, canonical.singular), kind


async def _food(session: AsyncSession, ingredient_id: uuid.UUID) -> Ingredient:
    ingredient = await session.get(Ingredient, ingredient_id)
    if ingredient is None:
        raise LookupError(f"nessun ingrediente {ingredient_id}")
    if ingredient.kind != IngredientKind.FOOD:
        raise NutritionRefusal(
            NON_FOOD_CODE,
            f"«{ingredient.display_name}» non è un alimento: non ha valori nutrizionali.",
        )
    return ingredient


async def set_grams(
    session: AsyncSession, ingredient_id: uuid.UUID, unit_id: uuid.UUID | None, grams: Decimal
) -> list[Weight]:
    """Il peso a mano. Vince sempre, anche su quello dell'AI."""
    await _food(session, ingredient_id)
    pair_unit, label, kind = await resolve_pair_unit(session, unit_id)
    if kind.measure != "pair":
        raise NutritionRefusal(
            MEASURED_UNIT_CODE,
            f"«{label}» è un'unità di peso o di volume: i grammi si contano da sé.",
        )
    if not Decimal("0") < grams <= GRAMS_MAX:
        raise NutritionRefusal(
            BAD_GRAMS_CODE, "Un peso va da più di 0 a 5000 g: controlla il numero."
        )
    statement = pg_insert(IngredientUnitGrams).values(
        id=uuid.uuid4(),
        ingredient_id=ingredient_id,
        unit_id=pair_unit,
        grams=grams,
        decided_by=NutritionDecider.HUMAN,
        decided_at=func.now(),
    )
    await session.execute(
        statement.on_conflict_do_update(
            constraint="uq_ingredient_unit_grams",
            set_={
                "grams": statement.excluded.grams,
                "decided_by": statement.excluded.decided_by,
                "decided_at": statement.excluded.decided_at,
            },
        )
    )
    return await weights_of(session, ingredient_id)


async def clear_grams(
    session: AsyncSession, ingredient_id: uuid.UUID, unit_id: uuid.UUID | None
) -> list[Weight]:
    """L'annullamento: la coppia torna da decidere, e l'AI la riprenderà."""
    await _food(session, ingredient_id)
    pair_unit, _, _ = await resolve_pair_unit(session, unit_id)
    await session.execute(
        delete(IngredientUnitGrams).where(
            IngredientUnitGrams.ingredient_id == ingredient_id, _same_unit(pair_unit)
        )
    )
    return await weights_of(session, ingredient_id)


async def apply_ai_grams(
    session: AsyncSession, ingredient_id: uuid.UUID, unit_id: uuid.UUID | None, grams: Decimal | None
) -> bool:
    """Il peso dell'AI (o «nessun peso», `None`), solo dove non c'è niente. `True` se l'ha
    scritto. `unit_id` è già quella della coppia (canonica, o None)."""
    result = await session.execute(
        pg_insert(IngredientUnitGrams)
        .values(
            id=uuid.uuid4(),
            ingredient_id=ingredient_id,
            unit_id=unit_id,
            grams=grams,
            decided_by=NutritionDecider.AI,
        )
        .on_conflict_do_nothing()
    )
    return result.rowcount == 1

# Quaranta coppie per chiamata: una risposta è ~30 token a coppia, ~1.200 per lotto, ben
# sotto il tetto. Le 800–1.500 coppie stimate per la produzione (spec §3) sono 20–40
# chiamate, meno di 0,05 $.
GRAMS_BATCH = 40
GRAMS_MAX_TOKENS = 3000

GRAMS_SYSTEM_PROMPT = (
    "Ricevi un elenco numerato di coppie ingrediente e unità di misura, prese da ricette "
    "italiane, ciascuna con un esempio di dose. Per ognuna scrivi quanti grammi pesa UNA "
    "unità di quell'ingrediente: il peso netto della parte che si mangia (senza buccia, "
    "guscio, osso o torsolo), per un pezzo di misura media. «pezzo» vuol dire un pezzo "
    "intero: un uovo, una cipolla, un limone.\n\n"
    "Regole:\n"
    '- "n", "ingrediente" e "unita" vanno riscritti identici a come te li ho passati.\n'
    '- "grammi" è un numero maggiore di zero; null se quell\'unità, per quell\'ingrediente, '
    "non ha un peso sensato.\n"
    "- Una risposta per ogni coppia, nessuna in più."
)

GRAMS_SCHEMA = {
    "type": "object",
    "properties": {
        "pesi": {
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "n": {"type": "integer"},
                    "ingrediente": {"type": "string"},
                    "unita": {"type": "string"},
                    "grammi": {"type": ["number", "null"]},
                },
                "required": ["n", "ingrediente", "unita", "grammi"],
                "additionalProperties": False,
            },
        }
    },
    "required": ["pesi"],
    "additionalProperties": False,
}


@dataclass(frozen=True)
class PairQuestion:
    ingredient: str
    unit_label: str
    example: str | None


def _read_grams(value: object) -> tuple[bool, Decimal | None]:
    """(si può applicare, grammi): `None` è «nessun peso»; un numero fuori misura, una
    stringa o un booleano non si applicano."""
    if value is None:
        return True, None
    if isinstance(value, bool) or not isinstance(value, (int, float)) or not math.isfinite(value):
        return False, None
    grams = Decimal(str(value)).quantize(Decimal("0.01"))
    if not Decimal("0") < grams <= GRAMS_MAX:
        return False, None
    return True, grams


def _same_text(answer: dict, field: str, expected: str) -> bool:
    return str(answer.get(field) or "").strip().casefold() == expected.casefold()


async def ask_grams(
    session: AsyncSession,
    questions: Sequence[PairQuestion],
    client: httpx.AsyncClient | None = None,
    spend: Spend | None = None,
) -> tuple[dict[int, Decimal | None], int]:
    """I pesi delle coppie chieste, per indice (da 0), e quante risposte si sono rifiutate.
    Una coppia che manca dal dizionario non ha avuto una risposta verificabile."""
    asked = dict(enumerate(questions, start=1))
    question = {
        "coppie": [
            {"n": n, "ingrediente": item.ingredient, "unita": item.unit_label, "esempio": item.example}
            for n, item in asked.items()
        ]
    }
    data = await complete_recorded(
        session,
        call_site=LlmCallSite.UNIT_GRAMS,
        system=GRAMS_SYSTEM_PROMPT,
        user=json.dumps(question, ensure_ascii=False),
        schema=GRAMS_SCHEMA,
        schema_name="grammi_unita",
        max_tokens=GRAMS_MAX_TOKENS,
        client=client,
        spend=spend,
    )
    weights: dict[int, Decimal | None] = {}
    refused = 0
    answered: set[int] = set()
    for answer in data.get("pesi") or []:
        if not isinstance(answer, dict):
            refused += 1
            continue
        n = answer.get("n")
        if type(n) is not int or n not in asked or n in answered:
            refused += 1
            continue
        item = asked[n]
        if not _same_text(answer, "ingrediente", item.ingredient) or not _same_text(
            answer, "unita", item.unit_label
        ):
            refused += 1
            continue
        answered.add(n)
        ok, grams = _read_grams(answer.get("grammi"))
        if not ok:
            refused += 1
            continue
        weights[n - 1] = grams
    return weights, refused


@dataclass(frozen=True)
class GramsRun:
    """Quel che un lancio ha fatto, e quel che resta."""

    weighed: int = 0
    none: int = 0
    refused: int = 0
    # le coppie ancora da pesare alla fine, non solo quelle del `--limit`
    pending: int = 0
    unavailable: str | None = None
    asked: int = 0


async def decide_grams(
    session: AsyncSession,
    client: httpx.AsyncClient | None = None,
    limit: int | None = None,
    after_batch: Callable[[], Awaitable[None]] | None = None,
    batch_size: int = GRAMS_BATCH,
) -> GramsRun:
    """Pesa le coppie da decidere, le prime `limit` per ingrediente e unità. Non fa
    commit: lo fa `after_batch` dopo ogni lotto. Al primo guasto dell'AI si ferma."""
    pairs = await pending_pairs(session, limit)
    weighed = none = refused = 0
    unavailable: str | None = None
    for start in range(0, len(pairs), batch_size):
        chunk = pairs[start : start + batch_size]
        try:
            answers, bad = await ask_grams(
                session,
                [PairQuestion(pair.ingredient_name, pair.unit_label, pair.example) for pair in chunk],
                client=client,
            )
        except LlmUnavailable as exc:
            unavailable = str(exc)
            break
        refused += bad
        for index, grams in answers.items():
            pair = chunk[index]
            if await apply_ai_grams(session, pair.ingredient_id, pair.unit_id, grams):
                if grams is None:
                    none += 1
                else:
                    weighed += 1
        await session.flush()
        if after_batch is not None:
            await after_batch()
    return GramsRun(
        weighed=weighed,
        none=none,
        refused=refused,
        pending=await count_pending_pairs(session),
        unavailable=unavailable,
        asked=len(pairs),
    )

"""I nutrienti di una ricetta, letti dal database (S4, fetta 2).

Una query per le righe — con l'unità canonica, l'alimento CIQUAL scelto e i suoi valori —
e una per i pesi delle coppie; poi la funzione pura (`app/domain/recipe_nutrition.py`),
che decide cosa si conta e cosa no. È ciò che P1 e P2 leggeranno.

import uuid

from sqlalchemy import func, select
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.orm import aliased

from app.db.models.ingredient import Ingredient
from app.db.models.nutrition import CiqualFood, IngredientNutrition

async def nutrition_lines(
    session: AsyncSession, recipe_id: uuid.UUID
) -> tuple[int | None, list[NutritionLine]]:
    recipe = await session.get(Recipe, recipe_id)
    if recipe is None:
        raise LookupError(f"nessuna ricetta {recipe_id}")
    seen = aliased(Unit)
    canonical = aliased(Unit)
    rows = (
        await session.execute(
            select(
                RecipeIngredient.ingredient_id,
                Ingredient.name.label("ingredient_name"),
                RecipeIngredient.quantity_text,
                RecipeIngredient.quantity_value,
                canonical.id.label("unit_id"),
                canonical.key.label("unit_key"),
                canonical.singular.label("unit_singular"),
                IngredientNutrition.ciqual_code,
                CiqualFood.nutrients,
            )
            .join(Ingredient, Ingredient.id == RecipeIngredient.ingredient_id)
            .outerjoin(seen, seen.id == RecipeIngredient.quantity_unit_id)
            .outerjoin(canonical, canonical.id == func.coalesce(seen.canonical_id, seen.id))
            .outerjoin(IngredientNutrition, IngredientNutrition.ingredient_id == RecipeIngredient.ingredient_id)
            .outerjoin(CiqualFood, CiqualFood.code == IngredientNutrition.ciqual_code)
            .where(RecipeIngredient.recipe_id == recipe_id)
            .order_by(Ingredient.name)
        )
    ).all()
    grams = await decided_grams(session, [row.ingredient_id for row in rows])
    lines = []
    for row in rows:
        kind = classify_unit(row.unit_key, row.unit_singular)
        pair_grams = None
        if kind.measure == "pair":
            pair_unit = None if kind.piece else row.unit_id
            pair_grams = grams.get((row.ingredient_id, pair_unit), (None, None))[0]
        lines.append(
            NutritionLine(
                ingredient_id=row.ingredient_id,
                ingredient_name=row.ingredient_name,
                quantity_text=row.quantity_text,
                value=row.quantity_value,
                unit_key=row.unit_key,
                unit_singular=row.unit_singular,
                pair_grams=pair_grams,
                # «nessun alimento adatto» (codice NULL) e «da decidere» sono la stessa
                # cosa per il conto: la riga non ha valori
                per_100g=row.nutrients if row.ciqual_code is not None else None,
            )
        )
    return recipe.servings, lines


async def recipe_nutrition_of(session: AsyncSession, recipe_id: uuid.UUID) -> RecipeNutrition:
    servings, lines = await nutrition_lines(session, recipe_id)
    return recipe_nutrition(lines, servings)

import { apiFetch } from "../../api/client";

/** I nutrienti di una ricetta come li manda il server (S4, fetta 2): la porzione, i valori
 * già arrotondati, su quante righe c'è ogni valore, e le righe fuori dal conto col loro
 * perché. Il conto lo fa il backend; qui restano le frasi. */
export type RecipeNutrient = {
  key: string;
  label: string;
  unit: string;
  main: boolean;
  value: number | null;
  lines: number;
};

export type MissingLine = {
  ingredient_id: string;
  ingredient_name: string;
  quantity_text: string | null;
  reason: "no_quantity" | "no_nutrients" | "no_weight";
  unit_label: string | null;
};

export type RecipeNutrition = {
  basis: "serving" | "recipe";
  servings: number | null;
  lines_total: number;
  lines_counted: number;
  nutrients: RecipeNutrient[];
  missing: MissingLine[];
  source: string;
};

export const recipeNutritionKey = (id: string) => ["recipe-nutrition", id] as const;

export function fetchRecipeNutrition(id: string) {
  return apiFetch<RecipeNutrition>(`/recipes/${id}/nutrition`);
}

export function missingText(line: MissingLine): string {
  if (line.reason === "no_quantity") return "senza una dose da pesare";
  if (line.reason === "no_nutrients") return "senza un alimento CIQUAL";
  return `manca il peso di «${line.unit_label ?? "pezzo"}»`;
}

export function captionText(data: RecipeNutrition): string {
  if (data.basis === "recipe" || data.servings === null) return "Per tutta la ricetta: porzioni non indicate";
  return `A porzione, su ${data.servings} ${data.servings === 1 ? "porzione" : "porzioni"}`;
}

export function countedText(counted: number, total: number): string {
  return counted === 1 ? `Contata 1 riga su ${total}.` : `Contate ${counted} righe su ${total}.`;
}

/** «su 2 righe di 3»: il valore viene solo da una parte delle righe contate. */
export function partialNote(nutrient: RecipeNutrient, counted: number): string | undefined {
  return nutrient.value !== null && nutrient.lines < counted ? `su ${nutrient.lines} righe di ${counted}` : undefined;
}
